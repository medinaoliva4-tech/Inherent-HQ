# Departamentos de Inherent — especificación

**Fuente:** definición de Inherent Global · 2026-09-15.
Este archivo es la **fuente de verdad del alcance de cada departamento**. Cuando el método de un
agente y esta especificación no coincidan, **manda esta especificación** — y se corrige el agente.

```
① Comprensión → ② Estrategia → ③ Marketing → ④ Creatividad → ⑤ Producción →  ⑥A Diseño  →  [Drive]  → ⑦ Posting → ⑧B Ads
                      ↓                ↑                                      ⑥B Video  ↗   HUMANO
                 ②B Branding ──────────┘                                                                   ⑨ Community ↻
```

---

## ① Comprensión

| | |
|---|---|
| **Recibe** | Información cruda del negocio, cliente, producto, metas y contexto actual |
| **Hace** | Ordena la realidad del negocio **antes** de crear cualquier estrategia |
| **Incluye** | Datos del cliente, edad, comportamiento, competencia, mercado, producto, precios, canales de venta, problemas actuales y oportunidades |
| **Entrega** | Documento claro de comprensión del negocio y del cliente |
| **Habilidades** | Investigación, análisis, escucha, síntesis, lectura de mercado |

## ② Estrategia

| | |
|---|---|
| **Recibe** | La comprensión completa del negocio |
| **Hace** | Define hacia dónde se va y por qué |
| **Incluye** | Las 3 verdades, ICP, villano, solución, historia de marca, objetivo financiero, posicionamiento, ingeniería inversa y **distribución por canales de ingreso** (reservas, delivery, eventos, productos, membresías) |
| **Entrega** | Estrategia final de temporada o trimestre |
| **Habilidades** | Pensamiento estratégico, finanzas básicas, posicionamiento, storytelling, ingeniería inversa |

## ②B Branding

| | |
|---|---|
| **Recibe** | La estrategia y la historia de marca, referencias (páginas de Instagram), insights (consumidor, competencia, diferenciación) |
| **Hace** | Define cómo debe **sentirse, verse y comunicarse** la marca |
| **Incluye** | Brand guidelines, tono de voz, estética visual (minimalista, colorido, etc.), referencias, colores, tipografías, dirección visual, personalidad y reglas de marca |
| **Entrega** | **Guía de marca aplicable para diseño, producción y contenido** |
| **Habilidades** | Dirección de arte, identidad visual, sensibilidad estética, branding, comunicación |

## ③ Marketing

| | |
|---|---|
| **Recibe** | La estrategia final y el branding |
| **Hace** | Convierte la estrategia en decisiones de marketing |
| **Incluye** | Market research primero. Campañas, tipos de marketing, canales, fechas importantes, fechas de preparación, lanzamientos, expectativa, promociones, distribución del objetivo y **frecuencia de contenido** — cuántos reels, historias y carruseles diarios se suben por campaña. Ej.: influencer marketing, Meta Ads, Google Ads, orgánico, eventos, campañas de temporada |
| **Entrega** | Plan de marketing y campañas, divididas en **orgánicas y pautadas** |
| **Habilidades** | Planeación, marketing digital, estrategia de campañas, comprensión de canales, calendario comercial |

## ④ Creatividad

| | |
|---|---|
| **Recibe** | El plan de marketing, campañas y branding |
| **Hace** | Llena el gap entre la estrategia y la ejecución visual |
| **Incluye** | Ideas creativas, feeling, emoción a evocar, formatos, conceptos, hooks, referencias, razonamiento creativo, **pilares de contenido**, propuestas visuales y la **estrategia 70/20/10** — 70% contenido que ya funcionó (Meta Ad Library), 20% contenido nuevo propio, 10% contenido propio que ya rindió |
| **Entrega** | **Excel de calendario creativo**, organizado por campañas, con ideas claras para producir (acciones, lugares, duración de escenas), **qué elementos gráficos diseñar** (ilustraciones, assets PNG, texturas, pinceladas, formas gráficas) o qué editar |
| **Habilidades** | Creatividad, criterio visual, storytelling, cultura digital, lectura de tendencias, dirección creativa |

## ⑤ Producción

| | |
|---|---|
| **Recibe** | El calendario creativo y las ideas aprobadas |
| **Hace** | Convierte las ideas en material real |
| **Incluye** | Videos necesarios, fotos necesarias, tomas, locaciones, personas, productos, props, preparación y grabación |
| **Entrega** | Excel con presupuesto y escenas planificadas + material producido: fotos, videos y assets base |
| **Habilidades** | Producción audiovisual, fotografía, dirección, organización, manejo de recursos |

## ⑥A Diseño gráfico

| | |
|---|---|
| **Recibe** | Guía de marca aplicable, la creatividad y las fotos producidas |
| **Hace** | Toma el contenido producido y el Excel de calendario creativo para crear **piezas visuales estáticas** por formato (historia o carrusel) y canal (Facebook o Instagram) |
| **Incluye** | Composición, jerarquía visual, layout, tipografía, color, contraste, adaptación a formatos, piezas en Figma, y los elementos gráficos superpuestos: ilustraciones (dibujos, trazos, iconos ilustrados, doodles), assets PNG recortados sin fondo (stickers, sellos), texturas (papel, grano, polvo, tela), pinceladas o brochas, y formas gráficas (círculos, líneas, flechas, marcos) |
| **Entrega** | **Diseños listos para publicar o pautar** |
| **Habilidades** | Diseño gráfico, composición, Figma, criterio visual, atención al detalle |

## Fronteras que esta especificación cierra

| Frontera | Resolución |
|---|---|
| **④ Creatividad ↔ ⑥A Diseño: el layout** | Creative especifica **qué** elementos gráficos pedir y el concepto. **Composición, jerarquía visual y layout son de ⑥A Diseño.** Creative define la jerarquía del MENSAJE; Diseño resuelve la jerarquía VISUAL |
| **Frecuencia de contenido** | Es de **③ Marketing** — cuántos reels, historias y carruseles diarios por campaña |
| **Distribución** | ② Estrategia distribuye por **canales de ingreso**. ③ Marketing distribuye **el objetivo y el contenido** |
| **⑧A Orgánico** | No existe como departamento. Lo orgánico vive dentro de ③ Marketing (campañas orgánicas y pautadas). La conversación es **⑨ Community management** |
| **La guía aplicable** | La produce **②B Branding**. ⑥A Diseño la construye solo en **D0 Modo B**, como respaldo, cuando Branding no entregó manual |

## Lo que queda abierto

1. **Strategy todavía carga las Capas 5-8** (sistema de contenido, calendario macro, medición), que
   según esta especificación son de ③ Marketing y ④ Creatividad. `PR #2` propone ese recorte.
2. **Medición / aprendizaje de negocio**: `mk-lectura` cierra el ciclo de campañas, pero ningún
   departamento cierra el círculo hacia ① y ②.
3. **⑨ Community management**: sin alcance detallado.
