# Capas 5-6 — Movimiento y Sistema

Leé `agents/strategy/METHOD.md` secciones **CAPA 5** y **CAPA 6** + la ficha del arquetipo.
Plantillas: `templates/estrategia-de-contenido.md` + `templates/contenido-por-canal.md`

**Input obligatorio:** `posicionamiento.md` aprobado (Gate 2).

---

## CAPA 5 — Movimiento

**5.1 Elegir 1-2 movimientos** de los candidatos de TRUTH 03. Documentá **por qué se descartan los
demás** (no apalancan una UNFAIR real, o el esfuerzo no es proporcional al resultado).
> Elegir todo es no elegir nada.

**5.2 Trabajo estratégico** en una frase:
```
La comunicación tiene que ______________ para que ______________.
```
Hasta acá **todavía no se decidió hacer un Reel, un evento ni una campaña.**

**5.3 Mecanismo:** `prueba · asociación · experiencia · historia · utilidad · identidad · espectáculo`
Dos preguntas: ¿aprovecha algo **unfair**? ¿resuelve mejor que comunicación ordinaria?

**5.4 Idea de campaña** — la que organiza el movimiento. Pasa el filtro D/N/R.

---

## CAPA 6 — Sistema

**6.1 Funciones** — el sistema real. Se eligen según necesidad, no hay que usar todas.
`Hero` atención · `Series` repetición · `Proof` confianza · `Utility` valor · `Conversion` acción ·
`Community` participación

**6.2 Pilares** — la capa táctica. Son **temas**, no el sistema. Cuelgan de las funciones.
**El mix lo dicta el arquetipo**, no una fórmula universal. Se ajusta por momento (lanzamiento,
temporada, crisis).

**6.3 Temperatura** — todo sistema plano falla:
```
FRÍO      alcance, ruptura de patrón, CEP
TIBIO     prueba, mecanismo, objeciones
CALIENTE  oferta, fricción, urgencia
CLIENTE   recurrencia, referidos, pertenencia
```

**6.4 Rol por canal** — **cada canal tiene una función distinta. Si dos hacen lo mismo, uno sobra.**
Por canal: función, temperatura, formatos, cadencia, métrica que lo juzga, qué NO se hace ahí.

**6.5 Especificación, no producción.** Strategy define qué **tipo** de pieza necesita el sistema.
Las piezas día por día son de Creative; los assets son de Production.

---

## Regla de trazabilidad (obligatoria)
```
Pieza → Canal → Sistema → Campaña → Mecanismo → Trabajo estratégico → Objetivo → MUST BE TRUE
```
Si un tipo de pieza no se puede trazar hacia atrás, **se elimina**. La pregunta correcta es:
*¿por qué estamos haciendo esto?*

## Reglas duras
- **El contenido es consecuencia de la cascada, nunca el punto de partida.** Nunca escribas
  "hagamos 20 piezas".
- La cadencia tiene que caber en la capacidad de producción real (`nucleo.md` sección C).
- No escribas copies, guiones ni ideas concretas. Eso es de Creative.
