# Flujo de colaboración entre departamentos

Este sistema no describe una jerarquía: describe cómo los departamentos se necesitan entre sí para convertir una estrategia en resultados medibles.

**Strategy + Growth** construyen la estrategia de marca con la metodología, investigación y calendario.

**Creative** transforma esa estrategia en ideas creativas.

**Branding** convierte y adapta esas ideas a las guidelines de la marca: lenguaje gráfico, visual, emocional y de tono.

**Preproducción, Producción y Postproducción** materializan las ideas respetando el branding.

**Content** reúne el calendario de Strategy + Growth, las ideas de Creative, las guidelines de Branding y las piezas de Producción para organizar el contenido final.

**Social Media Management** recibe el contenido en Drive y lo gestiona para su publicación.

**Media Buy** utiliza los activos y aprendizajes del contenido para distribuirlos mediante pauta.

**Analytics** mide el desempeño de contenido y pauta; sus aprendizajes regresan a Strategy + Growth para iniciar un nuevo ciclo.

`Strategy + Growth → Creative → Branding → Preproducción / Producción / Postproducción → Content → Social Media Management + Media Buy → Analytics → Strategy + Growth`
