# Contenido a Leads (Content-to-Lead Engine)

## Cuando se activa
Peticion de contenido organico (posts, videos, articulos) donde el fin es alimentar el funnel de leads, no solo awareness de marca.

## Proceso obligatorio

### Paso 1 - Una idea nuclear
Partir de UN problema/insight del avatar (idealmente el mismo problema #1 usado en growth-lead-magnet, para consistencia de mensaje).

### Paso 2 - Atomizacion
De la idea nuclear, generar variantes por plataforma (no copiar-pegar el mismo texto):
- Formato largo (articulo/video/podcast) = la version completa
- Formato corto (reel/short/carrusel) = un fragmento con gancho propio
- Formato texto (post/thread) = la idea condensada con una linea polemica o util

### Paso 3 - CTA de captura obligatorio
Cada pieza debe tener un CTA claro hacia el lead magnet o hacia agendar (no solo "sigueme"). Variar el CTA segun la etapa del funnel de esa pieza (tofu = lead magnet, mofu = agenda llamada).

### Paso 4 - Cadencia (Regla de 100)
Definir volumen y frecuencia sostenible por al menos 30-90 dias antes de evaluar CPL de contenido.

## Output obligatorio
```
IDEA NUCLEAR:
Formato largo:
Formato corto (x3 variantes):
Formato texto:
CTA por pieza:
Frecuencia/cadencia:
Metrica de exito (leads por pieza, no solo vistas):
```

## QA antes de entregar
- [ ] Cada pieza tiene un CTA de captura, no solo de vanidad (likes/follows)?
- [ ] Las variantes no son copy-paste, cada una tiene gancho propio para su plataforma?
- [ ] Se definio una metrica de leads generados, no solo alcance?

## Handoff
Leads capturados entran a growth-crm-seguimiento. Si el contenido requiere pauta para amplificar, pasar a growth-media-buying.
