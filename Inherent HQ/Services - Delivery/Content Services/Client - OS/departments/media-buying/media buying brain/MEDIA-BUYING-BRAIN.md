# Media Buying Brain

El brain operativo de Media Buying es el plugin de **Claude Ads** en Claude.

Ahí vive la metodología práctica: skills, agentes, flujos y comandos para auditorías, planificación, creativos, optimización y reportes.

No se deben copiar ni instalar esas skills por separado en este folder.

Para operar: abrir Claude con Claude Ads activo y usar sus flujos, por ejemplo `/claude-ads:ads setup`.

El contexto del cliente, exports, evidencia y entregables se guardan en `../inherent-operations-media-buying/`.
