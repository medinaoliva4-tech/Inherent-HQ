# Metodología operativa — Media Buying

La metodología operativa de Media Buying se ejecuta mediante el plugin de **Claude Ads** en Claude.

El plugin ya incluye las skills, agentes, flujos y comandos necesarios. No se deben instalar, copiar ni mantener por separado en este folder, para evitar duplicación y conflictos.

## Uso práctico

1. Abrir Claude con el plugin Claude Ads activo.
2. Configurar el cliente, KPIs y reglas con `/claude-ads:ads setup`.
3. Ejecutar desde el plugin las auditorías, planes, creativos, optimizaciones y reportes necesarios.

Este folder conserva únicamente el contexto del cliente, exports, evidencia y entregables de cada operación.
