# Pipeline — qué se activa cuando entra un cliente

> **La cadena de entrega completa.** Diez etapas, de la información cruda a la pieza publicada
> y el reporte. Cada etapa tiene un dueño, un input y un entregable.
>
> **`PAQUETES.md` dice QUÉ se promete. Este archivo dice CÓMO se entrega.**

---

## Los dos ciclos

```
┌─ ONBOARDING ──────────── una vez, al activar la cuenta ──────────────┐
│                                                                       │
│   01 COMPRENSIÓN → 02 ESTRATEGIA → 02B BRANDING → 03 MARKETING        │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
                                   │
                                   ▼
┌─ CICLO MENSUAL ───────── cada mes, para siempre ─────────────────────┐
│                                                                       │
│   04 CREATIVIDAD → 05 PRODUCCIÓN → 06 DISEÑO → 07 QA →                │
│   08 POSTING → 09 ADS → 10 COMMUNITY                                  │
│                                                                       │
│   ↻ El 20 de cada mes: REVISIÓN — qué funcionó, qué cambia            │
│                                                                       │
└───────────────────────────────────────────────────────────────────────┘
```

**Regla dura:** ninguna etapa arranca sin el entregable de la anterior.
**Si falta el input, se vuelve — no se improvisa.**

## CICLO MENSUAL — se corre cada mes

| **Entrega** | 📊 **Calendario creativo** con ideas listas para producir *(acciones, lugares, duración de escenas)*, elementos gráficos a diseñar y qué editar — **organizado por campaña** |
| **Habilidades** | Creatividad, criterio visual, storytelling, cultura digital, lectura de tendencias |
| **Corre en** | 🟦 · 🟪 · 🟨 |
| **Estado** | ⬜ **No construido** |

#### La regla 70 / 20 / 10

| % | Qué es | De dónde sale |
|---|---|---|
| **70%** | Contenido que **ya funcionó** en la categoría | Ingeniería inversa · AdWhispr · Eden |
| **20%** | Contenido **nuevo nuestro** | Apuesta creativa |
| **10%** | Contenido que **nos funcionó a nosotros** | Analítica propia |

> **Esta regla es lo que hace que el volumen no sea ruido.** 86 piezas al mes sin el 70% son
> 86 apuestas. Con el 70%, son 60 certezas y 26 apuestas.

### 07 · QA 🔴 **EL QUE FALTA Y TODO DEPENDE DE ÉL**

| | |
|---|---|
| **Agente** | `QA` |
| **Recibe** | Toda pieza terminada, antes de publicarse |
| **Hace** | **Revisa cada pieza contra el brief, la marca y el paquete.** Allan aprueba solo las excepciones |
| **Incluye** | ¿Cumple el brief? · ¿Respeta la guía de marca? · ¿Está dentro del paquete? · ¿El copy es correcto? · ¿Formato y canal correctos? · **predicción de viralidad** |
| **Entrega** | ✅ **Piezas aprobadas** + ⚠️ **lista de excepciones para Allan** |
| **Corre en** | 🟦 · 🟪 · 🟨 |
| **Estado** | 🔴 **NO CONSTRUIDO — es el bloqueador del modelo** |

> **A 204 piezas al mes, el QA humano son ~1 minuto por pieza. No alcanza.**
> **Sin este agente, las horas de Allan se duplican y los márgenes caen ~15 puntos.**
> **Es el primer agente a construir.** Ver `OPERACION.md` → hoja de ruta.

## 🎯 El orden de construcción

> **No se construye por orden del pipeline. Se construye por impacto.**

| # | Construir | Por qué ahora |
|---|---|---|
| **1** | 🔴 **QA** | Sin él el volumen no es entregable y el margen no cierra. **Bloquea todo** |
| **2** | **Creatividad** | Es el que produce las 86-204 piezas. Sin él no hay volumen que revisar |

| **4** | **Marketing** | Hoy el salto de Estrategia a Creatividad se hace a mano |

## 🔌 Cómo se opera desde Buzz

Cada agente se invoca en su propia sesión de Claude Code desde **Buzz**.

```
Buzz · canal por cliente
   │
   ├── "corré el onboarding de <cliente>"      → 01 · 02 · 02B · 03
   ├── "armá el mes de <cliente>"              → 04 · 05 · 06 · 07
   ├── "publicá lo aprobado de <cliente>"      → 08  🔒 gate de Allan
   ├── "lanzá las campañas de <cliente>"       → 09  🔒 gate de Allan
   └── "corré la revisión del 20 de <cliente>" → ↻
```

**Un canal por cliente. Nunca mezclar dos clientes en una sesión** — ver `CLAUDE.md`.

### Lo que dispara la activación de un cliente

| Momento | Qué corre | Entregable al cliente |
|---|---|---|
| **Día 1-7** | 01 · 02 · 02B | Documento de estrategia + guía de marca |
| **Día 8-12** | 03 · 04 | Plan de marketing + calendario creativo |
| **Día 13-18** | 05 | Sesión de grabación |
| **Día 19-25** | 06 · 07 | Piezas terminadas y aprobadas |
| **Día 26-30** | 08 · 09 | Publicación y campañas activas |
| **El 20, cada mes** | ↻ | Reporte y ajuste |

## Reglas del pipeline

| | |
|---|---|
| **Sin input no hay etapa** | Si falta el entregable anterior, se vuelve. No se improvisa |
| **Gate de Allan** | Publicar, pautar, enviar al cliente y borrar **siempre** pasan por él |
| **Un cliente por sesión** | Nunca mezclar dos en el mismo canal |
| **El paquete manda** | Antes de producir, se lee `PAQUETES.md`. El volumen es techo duro |
| **Lo que no está en Capacidades reales no se hace** | Sin MCP no hay acción |
