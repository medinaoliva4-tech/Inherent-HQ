## El modelo, en una pantalla

```
IDENTIDAD     Growth Operator — no agencia, no consultoría
                    │
MÉTODO        GROWTH OS       de dónde sale el crecimiento
              CONVERSION OS   que se cobre
              OPERATIONS OS   que la empresa lo aguante
              MONEY OS        que quede utilidad
                    │
OFERTA     🔷 MARKETING      $950    atención     arrancando → visible
           🔷 MARKETING PRO  $1,450  atención     visible → sostenido
           🟨 ACCELERATE     $2,500  facturación  estancado → escalando
           🟨 COMPOUND       $4,200  facturación  escalando → autónomo
                    │
DIVISIONES    LOW TICKET    volumen      oferta · big sales · upsells
              HIGH TICKET   precisión    oferta · cuentas grandes · expansión
```

## Las tres reglas que no se rompen

| | |
|---|---|
| **1** | **No vendemos servicios. Vendemos resultado.** El volumen y las herramientas son evidencia, no oferta |
| **2** | **Un sistema entra cuando el negocio tiene con qué alimentarlo.** Meterlo antes es cobrar por algo que no se usa |
| **3** | **Si la empresa es el estorbo, más demanda empeora el problema.** Se arregla la capacidad primero |
