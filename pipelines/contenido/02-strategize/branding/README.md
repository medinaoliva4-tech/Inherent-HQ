# Branding

> Convierte el brief de Strategy en **una marca que otro puede ejecutar sin preguntar**. Estrategia da dirección y restricciones; **Branding resuelve la forma**.

| | |
|---|---|
| **Pipeline** | Contenido |
| **Paso** | 02 · Strategize y 04 · Create |
| **Propósito de los pasos** | Strategize: definir cómo crecer, atraer atención y convertir esa atención en ingresos · Create: transformar datos y oportunidades en pilares, formatos, hooks, guiones y contenido |
| **Su responsabilidad** | **Strategize:** Definir cómo se posiciona y se reconoce la marca: territorio, voz y sistema visual<br>**Create:** Validar con `br-guardian` que cada pieza sea de marca antes de publicarse |
| **Artifact del equipo** | Interactive Growth Roadmap |
| **Entregable al cliente** | Ninguno propio |

## Skills

Playbooks: úsalos en el orden que convenga, no son trámites obligatorios.

| Skill | Para qué |
|---|---|
| [`br-brief`](brain/skills/br-brief/SKILL.md) | Carga el brief de Strategy desde los archivos de estrategia del cliente y verifica que esté completo antes de desarrollar nada. |
| [`br-territorio`](brain/skills/br-territorio/SKILL.md) | Define el territorio y la personalidad de la marca a partir del tipo y el posicionamiento que fijó Strategy. |
| [`br-voz`](brain/skills/br-voz/SKILL.md) | Define cómo suena la marca: el tono con sus ejes, los do's & don'ts con ejemplos reales del mismo mensaje bien y mal escrito, cómo se nombra la marca y qué palabras… |
| [`br-sistema`](brain/skills/br-sistema/SKILL.md) | El sistema visual con valores ejecutables, no adjetivos. |
| [`br-activos`](brain/skills/br-activos/SKILL.md) | Define los activos distintivos: lo que hace reconocible a la marca con el logo tapado. |
| [`br-aplicacion`](brain/skills/br-aplicacion/SKILL.md) | Baja el sistema a cada formato real donde la marca vive: reel, story, carrusel, estático, email, impresos. |
| [`br-guardian`](brain/skills/br-guardian/SKILL.md) | El guardián. |
| [`br-loop`](brain/skills/br-loop/SKILL.md) | Lee si la marca se está reconociendo o no. |
