# Growth

> Trabaja **de dónde sale el dinero**. Los tres pilares del Growth OS de la división que corresponda, más los sistemas que hacen que ese crecimiento se cobre y quede.

| | |
|---|---|
| **Pipeline** | Contenido |
| **Paso** | 02 · Strategize y 05 · Convert |
| **Propósito de los pasos** | Strategize: definir cómo crecer, atraer atención y convertir esa atención en ingresos · Convert: distribuir el contenido y conectar la atención con un sistema de adquisición y ventas |
| **Su responsabilidad** | **Strategize:** Cómo se va a monetizar: no solo la herramienta, también cómo se crea el deseo y la oportunidad de compra (oferta, canales grandes, upsells)<br>**Convert:** La conversión: que lo que ya llega se cobre |
| **Artifact del equipo** | Interactive Growth Roadmap |
| **Entregable al cliente** | `motor-de-crecimiento.md` |
