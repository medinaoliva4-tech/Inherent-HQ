# Marketing

> Traduce la estrategia en **el encargo del ciclo**. Marketing decide **qué se dice, dónde y cuándo**; Creatividad decide **cómo se dice**.

| | |
|---|---|
| **Pipeline** | Contenido |
| **Paso** | 02 · Strategize |
| **Propósito del paso** | Definir cómo crecer, atraer atención y convertir esa atención en ingresos |
| **Su responsabilidad** | Hacer real la atención que se quiere atraer: campaña, mensaje, pilares, canales y calendario. Cada slot traza a un KR de Attention o de Revenue |
| **Artifact del equipo** | Interactive Growth Roadmap |
| **Entregable al cliente** | Entra en la presentación del día 20 |

## Skills

Playbooks: úsalos en el orden que convenga, no son trámites obligatorios.

| Skill | Para qué |
|---|---|
| [`mk-encargo`](brain/skills/mk-encargo/SKILL.md) | Verifica qué decidió Strategy y qué se puede de verdad antes de planear nada. |
| [`mk-campana`](brain/skills/mk-campana/SKILL.md) | Define la idea de campaña que une todo el ciclo. |
| [`mk-mensaje`](brain/skills/mk-mensaje/SKILL.md) | La jerarquía de mensaje del ciclo: qué se dice primero, qué segundo y qué no se dice. |
| [`mk-pilares`](brain/skills/mk-pilares/SKILL.md) | Define el sistema de contenido: los pilares del ciclo, qué función cumple cada uno y con qué peso entran en la mezcla. |
| [`mk-canales`](brain/skills/mk-canales/SKILL.md) | Arma la ficha de cada canal del ciclo con su función única y, sobre todo, con qué NO se hace ahí. |
| [`mk-calendario`](brain/skills/mk-calendario/SKILL.md) | Arma `calendario.csv`, el encargo que recibe Creatividad. |
| [`mk-loop`](brain/skills/mk-loop/SKILL.md) | El cierre del ciclo. |
