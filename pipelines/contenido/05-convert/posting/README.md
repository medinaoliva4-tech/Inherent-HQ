# Posting

> Toma lo que Diseño gráfico y Video Editing terminaron y lo deja **listo para salir** — con el caption final, la ficha técnica verificada, la fecha y la hora, y **programado en Zernio** después de su auto-revisión. Creatividad escribe **el mensaje**; Posting lo **adapta a la plataforma** y lo **agenda**.

| | |
|---|---|
| **Pipeline** | Contenido |
| **Paso** | 05 · Convert |
| **Propósito del paso** | Distribuir el contenido y conectar la atención con un sistema de adquisición y ventas |
| **Su responsabilidad** | Distribuir: dejar lo aprobado programado y publicado donde está la audiencia |
| **Artifact del equipo** | Revenue Engine |
| **Entregable al cliente** | Ninguno propio |

## Skills

Playbooks: úsalos en el orden que convenga, no son trámites obligatorios.

| Skill | Para qué |
|---|---|
| [`po-recepcion`](brain/skills/po-recepcion/SKILL.md) | Verifica qué llegó y está realmente publicable antes de escribir un solo caption. |
| [`po-caption`](brain/skills/po-caption/SKILL.md) | Convierte el copy literal de Creatividad en el caption que sale, adaptado al largo y la forma de cada plataforma sin cambiar el mensaje. |
| [`po-specs`](brain/skills/po-specs/SKILL.md) | El QA técnico antes de programar. |
| [`po-programacion`](brain/skills/po-programacion/SKILL.md) | Fija la hora y la cuenta de cada publicación y verifica que nada se pise. |
| [`po-carga`](brain/skills/po-carga/SKILL.md) | Programa el ciclo en Zernio. |
| [`po-verificacion`](brain/skills/po-verificacion/SKILL.md) | Revisa en Zernio el estado de cada publicación del ciclo: programada, publicada o fallida. |
| [`po-loop`](brain/skills/po-loop/SKILL.md) | Cierra el ciclo con las cuatro lecturas: qué no llegó a tiempo y de dónde venía, qué se devolvió y por qué, qué falló al publicar, y si el ciclo quedó programado a… |
