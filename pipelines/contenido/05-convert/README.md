# 05 · Convert — Distribution & Monetization

> **Propósito del paso:** distribuir el contenido y conectar la atención con un sistema de
> adquisición y ventas. Una pieza que nadie ve no cuenta, y una atención que no se cobra tampoco.

## Qué le toca a cada agente

| Agente | Su responsabilidad en este paso |
|---|---|
| **Posting** | Distribuir: dejar lo aprobado programado y publicado donde está la audiencia del cliente |
| **Ads Management** | Distribuir con dinero lo que ya funciona hacia un sistema de adquisición y ventas. **Compra resultado, no alcance** |
| **Community Management** | Conectar la atención con la conversación: responder y llevar cada comentario o DM a un siguiente paso |
| **Growth** | La conversión: que lo que ya llega se cobre. Lo que el plan active *(`gr-conversion`)* |

## Artifact y entregable

| | |
|---|---|
| **Artifact del equipo** | Revenue Engine |
| **Entregable al cliente** | Ninguno propio |
