## Skills

Playbooks: úsalos en el orden que convenga, no son trámites obligatorios.

| Skill | Para qué |
|---|---|
| [`ad-encargo`](brain/skills/ad-encargo/SKILL.md) | Fija el objetivo en una métrica, el presupuesto aprobado y qué se está vendiendo, antes de tocar una cuenta. |
| [`ad-estructura`](brain/skills/ad-estructura/SKILL.md) | Arma la estructura de campañas y públicos: cuántas campañas, con qué objetivo cada una, qué públicos y con qué presupuesto. |
| [`ad-creativos`](brain/skills/ad-creativos/SKILL.md) | Elige qué piezas del ciclo se pautan y con qué variantes de hook, porque la pauta no testea creativos distintos sino hooks distintos sobre el mismo cuerpo. |
| [`ad-lanzamiento`](brain/skills/ad-lanzamiento/SKILL.md) | Lanza lo aprobado. |
| [`ad-optimizacion`](brain/skills/ad-optimizacion/SKILL.md) | Lee pacing, fatiga y rendimiento, y decide qué se mueve. |
| [`ad-atribucion`](brain/skills/ad-atribucion/SKILL.md) | Mide qué ventas vinieron de nuestro trabajo y cuáles no, que es lo que habilita el performance fee. |
| [`ad-loop`](brain/skills/ad-loop/SKILL.md) | Cierra el ciclo con cuatro lecturas: qué hook ganó, qué público rindió, cuánto duró cada creativo antes de fatigar y cuánto costó cada resultado. |
| [`growth-unit-economics`](brain/skills/growth-unit-economics/SKILL.md) | Evalúa si lo que hacen las campañas es rentable para el cliente: CAC, margen, recuperación y escala. |
