# 04 · Create — Creative Strategy & Production

> **Propósito del paso:** transformar datos y oportunidades en pilares, formatos, hooks, guiones y
> contenido.

Si Marketing dice que hay que hacer una campaña con ciertos formatos, cierta frecuencia y ciertos
videos, este paso **transforma esos datos de una manera creativa** y los hace existir.

## Qué le toca a cada agente

| Agente | Su responsabilidad en este paso |
|---|---|
| **Creative** | Convertir el encargo de Marketing en ideas dirigidas: BIG IDEA, hooks, guiones y plan de contenido. **Dirige** |
| **Production** | Planificar la producción y hacer que el material exista: fotos, videos y assets base |
| **Graphic Design** | Producir estáticos, carruseles y stories dentro del sistema visual |
| **Video Editing** | Ensamblar el material grabado en las piezas finales y multiplicarlo en derivados |
| **Branding** | **Validar** con `br-guardian` que cada pieza sea de marca antes de que se publique |

## Artifact y entregable

| | |
|---|---|
| **Artifact del equipo** | AI Creative Studio |
| **Entregable al cliente** | La presentación del día 20 *(el ciclo completo)* · la página de aprobación de los videos *(Video Editing)* · `presupuesto.md` de rodaje *(Production)* |
