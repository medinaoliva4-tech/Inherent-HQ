# Production

> Convierte las ideas de Creatividad en **material real** —fotos, videos y assets base— dentro de un presupuesto y una agenda que construye él mismo. Creatividad **dirige**; Producción **hace que exista**.

| | |
|---|---|
| **Pipeline** | Contenido |
| **Paso** | 04 · Create |
| **Propósito del paso** | Transformar datos y oportunidades en pilares, formatos, hooks, guiones y contenido |
| **Su responsabilidad** | Planificar la producción y hacer que el material exista: fotos, videos y assets |
| **Artifact del equipo** | AI Creative Studio |
| **Entregable al cliente** | `presupuesto.md` de rodaje; entra en la presentación del día 20 |

## Skills

Playbooks: úsalos en el orden que convenga, no son trámites obligatorios.

| Skill | Para qué |
|---|---|
| [`pr-brief`](brain/skills/pr-brief/SKILL.md) | Verifica qué hay que producir antes de gastar un minuto en desglosar. |
| [`pr-desglose`](brain/skills/pr-desglose/SKILL.md) | Convierte cada escena verificada en la lista concreta de cosas que alguien tiene que conseguir, con las 8 categorías: locación, talento, producto, props, vestuario,… |
| [`pr-jornadas`](brain/skills/pr-jornadas/SKILL.md) | La consolidación: convierte N escenas dispersas en M jornadas ejecutables, al menor costo posible y sin tocar una sola decisión creativa. |
| [`pr-recursos`](brain/skills/pr-recursos/SKILL.md) | De dónde sale cada cosa, quién la consigue y para cuándo. |
| [`pr-presupuesto`](brain/skills/pr-presupuesto/SKILL.md) | Cuesta el ciclo por jornada (nunca por pieza), separa los cinco bloques de costo, declara la contingencia como línea propia según el perfil del rodaje, calcula el… |
| [`pr-rodaje`](brain/skills/pr-rodaje/SKILL.md) | Convierte las jornadas presupuestadas en call sheets ejecutables: uno por jornada, con encabezado y dirección, horarios, contactos con teléfono, orden de tiro por… |
| [`pr-entrega`](brain/skills/pr-entrega/SKILL.md) | Cierra el rodaje y entrega el material de forma que Diseño gráfico y Video Editing puedan trabajar sin renombrar ni preguntar. |
| [`pr-loop`](brain/skills/pr-loop/SKILL.md) | Cierra el ciclo con datos reales y no con impresiones. |
