# Graphic Design

> Produce **el grueso del volumen** —estáticos, carruseles y stories— dentro del sistema visual que Branding definió. Creatividad dirigió, **Diseño gráfico compone**.

| | |
|---|---|
| **Pipeline** | Contenido |
| **Paso** | 04 · Create |
| **Propósito del paso** | Transformar datos y oportunidades en pilares, formatos, hooks, guiones y contenido |
| **Su responsabilidad** | Producir estáticos, carruseles y stories dentro del sistema visual |
| **Artifact del equipo** | AI Creative Studio |

## Skills

Playbooks: úsalos en el orden que convenga, no son trámites obligatorios.

| Skill | Para qué |
|---|---|
| [`gd-recepcion`](brain/skills/gd-recepcion/SKILL.md) | Verifica qué llegó de Creatividad y es realmente componible antes de abrir un archivo. |
| [`gd-plantillas`](brain/skills/gd-plantillas/SKILL.md) | Arma el sistema de plantillas del ciclo, que es lo que hace posible producir 168 piezas sin tomar 168 decisiones. |
| [`gd-imagen`](brain/skills/gd-imagen/SKILL.md) | Resuelve de dónde sale la imagen de cada pieza, en orden de costo: banco propio, material de Producción o pedirle al cliente. |
| [`gd-composicion`](brain/skills/gd-composicion/SKILL.md) | Llena las plantillas del ciclo con el copy literal de Creatividad y las imágenes resueltas, pieza por pieza y por formato agrupado. |
| [`gd-export`](brain/skills/gd-export/SKILL.md) | Exporta cada pieza con las specs de su formato y la nomenclatura que Posting cruza, y arma el manifiesto del ciclo. |
| [`gd-loop`](brain/skills/gd-loop/SKILL.md) | Cierra el ciclo con cuatro lecturas: qué plantilla se usó más y cuál no se usó nunca, cuántas piezas se devolvieron y por qué regla, cuánto del banco de imágenes se… |
