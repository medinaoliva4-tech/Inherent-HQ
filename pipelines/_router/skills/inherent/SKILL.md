# ¿Por dónde empiezo?

El pipeline de contenido tiene seis pasos y no se saltan: ver `pipelines/contenido/README.md`.

| Si el pedido es sobre… | Paso | Agente |
|---|---|---|
| Entender el negocio, su cliente, sus objetivos | 01 Understand | Strategy `context` |
| Estrategia, OKRs, roadmap, posicionamiento | 02 Strategize | Strategy |
| Marca: territorio, voz, sistema visual, «¿esto es de marca?» | 02 / 04 | Branding |
| Oferta, canales grandes, upsells, conversión | 02 / 05 | Growth |
| Plan del ciclo, campañas, pilares, calendario | 02 Strategize | Marketing |
| Audiencia, competencia, referentes, tendencias, winners | 03 Research | Research |
| Ideas, hooks, guiones, shot list | 04 Create | Creative |
| Rodaje, locaciones, presupuesto | 04 Create | Production |
| Estáticos, carruseles, stories | 04 Create | Graphic Design |
| Reels, edición, derivadas | 04 Create | Video Editing |
| Programar y publicar | 05 Convert | Posting |
| Pauta, CPA, ROAS, atribución | 05 Convert | Ads Management |
| Comentarios, DMs, la bandeja | 05 Convert | Community Management |
| Cómo van las cuentas, KR, qué ajustar | 06 Optimize | Performance |

Cada agente tiene su `README.md` con sus skills. **Un cliente por sesión.** Si el pedido toca dos
pasos, empieza por el primero.
