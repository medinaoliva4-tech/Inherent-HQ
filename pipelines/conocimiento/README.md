# Conocimiento

> **Tres cosas que no se confunden.** **Conocimiento** = libros, documentación, cursos y casos.
> **Skills** = procedimientos para ejecutar tareas con ese conocimiento. **Agentes** = quienes usan
> skills y herramientas para correr un flujo de varios pasos. Un MCP solo conecta capacidades o datos.

No se crea un agente por cada actividad: se construye **una base de conocimiento** y un conjunto de
**skills especializadas** que los agentes del pipeline consultan. El objetivo es que la IA entienda
**por qué** toma una decisión y **cómo contribuye a generar ingresos** para el cliente.
