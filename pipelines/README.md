# Los pipelines

Un **pipeline** es el camino que recorre un negocio para crecer. Cada **paso** es un
**departamento**, y cada departamento tiene los **agentes** que trabajan su resultado.

```
pipelines/
├── 00-account/     la secretaria — vive fuera del pipeline
├── _router/        un mapa: ¿en qué paso cae este pedido?
└── contenido/      el pipeline de contenido (seis pasos) → ver contenido/README.md
```

Cada agente tiene `README.md` (qué hace, sus skills, sus herramientas) y `brain/skills/<skill>/`.
Los skills son playbooks: úsalos con criterio.
