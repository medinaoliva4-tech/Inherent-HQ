# Capa 3 · Composición — llenar las plantillas

| | |
|---|---|
| **Consume** | Las plantillas con GATE 1 · las imágenes de la Capa 2 · el **copy literal** de ④ |
| **Produce** | Las piezas compuestas, antes de exportar |

> 🔑 **Esta capa es ejecución, no diseño.** Si una pieza pide una decisión nueva, **la plantilla
> está mal** — se vuelve a la Capa 1.

## 1 · Se produce por formato, no por fecha

**Todos los carruseles juntos, todos los estáticos juntos, todas las stories juntas.** Es lo que
la Capa 0 agrupó.

## 2 · El copy va literal

🛑 **El texto es el que ④ escribió.** No se acorta, no se mejora, no se corrige el estilo.

| Si el copy no entra | Qué se hace |
|---|---|
| Se pasa por poco | Se revisa la jerarquía de la plantilla |
| Se pasa de verdad | ↩️ **Se devuelve a ④** con el máximo de caracteres que entra |

🛑 **Acortar el copy en ⑥A rompe el hook que ④ diseñó**, y nadie se entera hasta el loop.

## 3 · Las cuatro verificaciones de cada pieza

| | Qué se mira |
|---|---|
| **Jerarquía** | Se lee en el orden que el sistema define: 1°, 2°, 3° |
| **Un foco visual** | **Uno solo.** Si todo resalta, nada resalta |
| **Safe zones** | Ningún texto bajo la UI, la zona del CTA ni el pulgar |
| **Un acento** | **Un solo color de acento por pieza** |

## 4 · El carrusel tiene dos reglas propias

| | Regla |
|---|---|
| **La slide 1 se entiende sola** | Es la única que la mayoría va a ver |
| **Cada slide se sostiene sola** | Nadie garantiza que deslicen en orden |

🛑 **Una slide 1 que dice *«deslizá para ver»* y nada más desperdicia la única impresión que
tenés asegurada.**

## 5 · La story tiene una regla propia

**Lleva activo distintivo igual que todo lo demás.** El *«es efímero»* es la razón por la que
las stories de la mayoría de las marcas no se reconocen.

## 6 · La auto-revisión contra ②B

**Antes de exportar, se corre el checklist del guardián sobre la propia pieza:**

- [ ] ¿Un solo acento?
- [ ] ¿Tipografías del sistema, con su peso?
- [ ] ¿Texto dentro de safe zones?
- [ ] ¿Los activos que el formato exige?
- [ ] **Logo tapado: ¿se reconoce la marca?**

> 🔑 **Auto-revisarse acá es más barato que que lo devuelva `br-guardian` con 168 piezas hechas.**

## 7 · Checklist

- [ ] Se produjo **por formato agrupado**
- [ ] El copy está **literal**, como lo escribió ④
- [ ] Lo que no entró **se devolvió a ④**, no se acortó
- [ ] Cada pieza pasó las **cuatro verificaciones**
- [ ] Cada **slide 1** se entiende sola
- [ ] Las stories llevan **activo distintivo**
- [ ] Ninguna pieza necesitó una **decisión nueva** *(si pasó, la plantilla está mal)*
