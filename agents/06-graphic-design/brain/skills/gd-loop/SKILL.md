# Capa 5 · Loop — qué plantilla rindió y qué falta al sistema

| | |
|---|---|
| **Consume** | `entregas-diseno.md` · las devoluciones del ciclo · métricas de ⑨ y ⑩ |
| **Produce** | **`aprendizaje-de-diseno.md`** |

> 🔑 **Corre el 20 de cada mes.**

## 1 · Las cuatro lecturas

### A · Uso de plantillas
**Se cuenta desde la columna `plantilla` del manifiesto.**

| Resultado | Decisión |
|---|---|
| Una plantilla llevó más del 40% del ciclo | 🟡 El ciclo se ve monótono. Se revisa el reparto |
| Una plantilla no se usó nunca | **Sale** del set |
| Una plantilla rindió mejor en métricas | **Sube** su peso el próximo ciclo |

### B · Devoluciones por regla
**Agrupadas, no contadas sueltas.** Si la misma regla se incumple siempre, **el problema es la
regla o la plantilla, no el descuido.**

### C · Reutilización del banco
```
imágenes del banco ÷ imágenes totales del ciclo
```

| Ciclo | Lo esperado |
|---|---|
| **1º** | Cerca de 0% |
| **3º** | **Al menos 50%** |

🔴 **Si en el tercer ciclo sigue cerca de 0%, el banco no se está alimentando** — y cada ciclo
cuesta lo mismo que el primero.

### D · Qué le faltó al sistema visual
**Las preguntas que la Capa 1 tuvo que devolver a ②B.** Si se repiten, `sistema-visual.md`
tiene un hueco estructural.

## 2 · Las plantillas que pasan al próximo ciclo

| Veredicto | Cuándo |
|---|---|
| ✅ **Se guarda** | Se usó y no generó devoluciones |
| 🔧 **Se arregla** | Se usó pero generó devoluciones por la misma regla |
| 🗑️ **Sale** | No se usó |

> 🔑 **La meta es que el ciclo 3 agregue una plantilla, no doce.**

## 3 · ⚠️ Sin datos no se concluye

Si no hay métricas por pieza, **no se declara qué plantilla rindió mejor**: se marca
`⚠️ SIN DATOS` y se nombra a quién se le piden.

## 4 · Qué escribe

| Bloque | Qué lleva |
|---|---|
| **A · Uso de plantillas** | Tabla con plantilla, piezas, %, veredicto |
| **B · Devoluciones por regla** | Agrupadas, con diagnóstico |
| **C · Reutilización del banco** | El %, contra lo esperado del ciclo |
| **D · Huecos del sistema visual** | Las preguntas devueltas a ②B que se repitieron |
| **E · El set del próximo ciclo** | Qué se guarda, qué se arregla, qué sale |

## 5 · Checklist

- [ ] El uso de plantillas está **contado** desde el manifiesto
- [ ] Las devoluciones están **agrupadas por regla**
- [ ] La **reutilización del banco** está calculada contra lo esperado
- [ ] Los huecos del sistema visual **se devolvieron a ②B**
- [ ] El set del próximo ciclo está **decidido**
- [ ] Ninguna conclusión de rendimiento está hecha **sin datos**
