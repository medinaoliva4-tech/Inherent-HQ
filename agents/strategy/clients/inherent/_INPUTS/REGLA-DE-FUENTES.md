# Regla de fuentes — Inherent

**Establecida por Rodrigo Medina, 2026-09-07.**

> Solo se usa la información que el usuario entrega directamente.

## Qué significa
- ❌ No se leen otros repos, cuentas, workspaces ni archivos que el usuario no haya entregado
- ❌ No se infiere data del cliente desde fuentes internas no autorizadas
- ✅ Se usa el intake y lo que el usuario pegue en la conversación
- ⚠️ Lo que falte se marca `⚠️ SIN DATOS`, nunca se completa por otra vía
