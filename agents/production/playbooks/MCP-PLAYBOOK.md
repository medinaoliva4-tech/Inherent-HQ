# Playbook — MCPs y herramientas de Producción

**Qué resuelve.** Qué herramienta se usa en cada capa, con qué permiso, y qué **no** se hace con
ellas desde este departamento.

> Las buenas prácticas generales de uso de MCPs están en `agents/strategy/playbooks/MCP-PLAYBOOK.md`.
> Acá solo lo específico de Producción.

## Qué NO se hace desde Producción

| Herramienta | Por qué no |
|---|---|
| **Figma** | Componer, diagramar y exportar es de **⑥A Diseño gráfico** |
| **Editores y color** | El montaje, el color de entrega y las versiones son de **⑥B Video Editing** |
| **Generadores de media** (imagen, video) | Producción consigue material **real**. Si la pieza pide media generada, la genera ⑥A a partir del brief de ④ |
| **Editores de video** | El montaje final, el color de entrega y las versiones por plataforma son de **⑥B Video Editing** |
| **Meta Ads / Ad Library** | Es de ⑧B Ads y de ④ Creatividad (swipe file) |
| **Publicación y programación** | Es de ⑦ Posting |

🛑 **Producción entrega RAW y selects.** Toda herramienta que produzca un archivo "listo para
publicar" está fuera de alcance.

---

## Reglas de permiso

1. **Nada se escribe afuera antes de su gate.** El Sheet después del GATE 1, el calendario después
   del GATE 2, el Drive después del GATE 3.
2. **Nada destructivo.** No se borra material, ni siquiera el descarte. Se marca.
3. **Ninguna reserva ni compromiso** —locación, equipo, talento— antes del GATE 1. Un "aparté la
   fecha por las dudas" es un compromiso.
4. **Toda cotización se registra con fecha y moneda.** Un número sin fecha no sirve para la Capa 7.
5. **Los datos de contacto del talento y los proveedores** no salen del repo del cliente ni se pegan
   en herramientas externas sin necesidad operativa.
