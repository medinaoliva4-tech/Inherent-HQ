# Toolkit de Producción — 7 taxonomías

**Por qué existe esto.** Un desglose no se hace de memoria, una jornada no se arma por intuición y un
presupuesto no se estima a ojo. Cada decisión logística sale de una **taxonomía cerrada**, para que
sea repetible, auditable y comparable entre ciclos.

**Cómo funciona.** Cada capa del método usa una o dos fichas. La ficha da las opciones; el desglose
del ciclo decide cuál.

| Ficha | Capa | Qué decide | Columnas del Excel |
|---|---|---|---|
| `01-desglose.md` | 1 | Las 8 categorías, y qué entra en cada una | `talento` `producto` `props` `vestuario` `arte_ambientacion` `equipo` `permisos` |
| `02-locaciones.md` | 1-3 | Qué hace a un lugar viable, y qué se chequea antes de confirmarlo | `locacion` `permisos` |
| `03-talento.md` | 1-3 | Tipos de participación, qué se firma, cómo se dirige | `talento` |
| `04-equipo.md` | 1-3 | Qué equipo pide cada encuadre, y cuánto tarda cada setup | `equipo` `tiempo_estimado_min` |
| `05-cobertura.md` | 5-6 | Las tomas de seguridad innegociables | — *(checklist de cierre)* |
| `06-presupuesto.md` | 4 | Estructura de costos y contingencia | `costo_estimado` `costo_real` |
| `07-entrega.md` | 5-6 | Nomenclatura y estructura de carpetas | `archivo_entregado` `destino` |

---

## Estructura de cada ficha

Todas responden lo mismo, en el mismo orden:

1. **Qué decide** — y en qué capa se usa
2. **La taxonomía** — las opciones cerradas
3. **Reglas duras** — lo que no se negocia
4. **Tiempos y costos de referencia** — para estimar, y que la Capa 7 corrija
5. **Anti-patterns** — los errores que se repiten siempre acá

## Las fichas se actualizan solas

Los tiempos y costos de referencia de estas fichas **no son fijos**: la Capa 7 los corrige con el
dato real de cada ciclo. Un tiempo estimado que falló tres ciclos seguidos deja de ser estimación y
pasa a ser dato. **Ese es el mecanismo por el que el departamento mejora sin que nadie lo decida.**
