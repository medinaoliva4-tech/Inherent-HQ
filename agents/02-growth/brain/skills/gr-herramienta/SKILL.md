🛑 **Es promesa publicada.** *«Herramientas hechas para ti, una nueva cada trimestre»* ·
*«Tu operación más liviana: una herramienta nueva cada mes»*.

## 2 · Qué se construye: el cuello, no el deseo

**La herramienta sale de dónde se traba el trabajo, no de una lista de deseos.**

| Se construye cuando… | Ejemplo |
|---|---|
| Alguien hace lo mismo a mano **todos los días** | Un panel que junta lo que hoy se busca en tres lados |
| **Se pierde información** entre dos pasos | Un registro que no se pierde |
| El cliente **no puede ver** algo que necesita ver | Un tablero de su operación |
| Una venta **se cae por fricción** | Una landing o un flujo de pago más corto |

🛑 **No se construye porque suena moderno.** Una herramienta sin cuello que destrabar es trabajo
que nadie va a usar.

## 4 · Las tres reglas de construcción

| | Regla | Por qué |
|---|---|---|
| **1** | **Resuelve una cosa** | Una herramienta que hace cinco cosas no la usa nadie |
| **2** | **Vive donde ya trabajan** | Si hay que abrir otra pestaña, se abandona |
| **3** | **Funciona sin nosotros** | Si depende de que alguien de Inherent la corra, no es del cliente |

## 5 · La prueba de las dos semanas

> 🔑 **Si a las dos semanas nadie la usó, la herramienta está muerta.**

**Se declara, no se disimula.** Y se aprende:

| Causa probable | Qué se corrige |
|---|---|
| No era el cuello | Se vuelve al paso 2 con el cuello real |
| Vive fuera del flujo | Se mueve a donde trabajan |
| Nadie supo que existía | Faltó el traspaso, no la herramienta |

## 6 · El traspaso — sin esto no cuenta como entregada

| | |
|---|---|
| **Quién la usa** | Con nombre |
| **Cómo se usa** | Corto. Si necesita manual, está mal diseñada |
| **Qué pasa si falla** | A quién se le avisa |
| **De quién es** | 🔴 **Del cliente.** Las credenciales y el acceso son suyos |

## 7 · Qué escribe

`## § Herramientas`:

| Bloque | Qué lleva |
|---|---|
| **A · El cuello** | Qué se traba hoy, con evidencia |
| **B · Qué se construyó** | Y qué **no** hace |
| **C · El traspaso** | Quién, cómo, qué si falla |
| **D · La revisión de 2 semanas** | Se usó o no, y qué se aprendió |
| **E · Las anteriores** | Qué se construyó antes y si sigue viva |

## 8 · Checklist
