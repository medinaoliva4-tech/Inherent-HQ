# Capa 4 · Conversión — que lo que llega se cobre

| | |
|---|---|
| **Consume** | § La oferta · cómo se compra, de ① Comprensión |
| **Produce** | La sección **§ Conversión** de `motor-de-crecimiento.md` |

## 1 · ⛔ No entra en la línea Marketing

🛑 **Antes no hay nada que perder.** Un sistema de conversión sobre 3 mensajes al mes es
infraestructura sin uso.

> 🔑 **Es una promesa publicada de Accelerate:** *«Nadie que te escribe se queda sin respuesta.»*

## 2 · Primero se mapea dónde se pierde

**Antes de automatizar nada, se dibuja el recorrido real y se marca dónde se cae la gente.**

| Punto | La pregunta |
|---|---|
| **Llega** | ¿Por dónde entra? ¿DM, WhatsApp, formulario, llamada, presencial? |
| **Pregunta** | ¿Cuánto tarda en recibir respuesta **hoy**? |
| **Decide** | ¿Qué le falta saber para decidir? |
| **Compra** | ¿Qué fricción tiene el pago o el cierre? |
| **No compra** | ¿Qué pasa con él? **Casi siempre: nada** |

🛑 **Automatizar un embudo que no se mapeó es automatizar el desorden.**

## 3 · Los tres frentes

### A · Que nadie se quede sin respuesta
| | |
|---|---|
| **Respuesta inmediata** | Aunque sea para decir cuándo responde alguien |
| **Fuera de hora** | Zapier → ManyChat / WhatsApp Business |
| **Las 5 preguntas de siempre** | Respondidas antes de que las haga |

### B · Que el interesado no se enfríe
| | |
|---|---|
| **Seguimiento sin que nadie se acuerde** | Zapier + el registro del negocio |
| **Cuántos toques y cada cuánto** | Definido, no improvisado |
| **Cuándo se deja de insistir** | También definido |

### C · Que el equipo sepa cerrar
| | |
|---|---|
| **Guiones** | Para las situaciones reales, no un pitch |
| **Objeciones** | Las 3 que más frenan, con la respuesta escrita |
| **Entrenamiento** | Cómo se practica |

> 🔑 **Es una promesa publicada:** *«que tu equipo sepa cerrar»*.

## 4 · ⚠️ Responder al cliente final es acción hacia afuera

🛑 **Toda respuesta automática pasa por gate de Allan antes de encenderse.**
Un auto-DM mal escrito le habla a todos los clientes del cliente.

## 5 · Compound — que se sostenga solo

**Se suma lo que hace que el crecimiento no dependa de la pauta:** referidos, comunidad propia,
recompra — y la **IA propia del cliente** con `create_custom_ai`, entrenada con su conocimiento.

## 6 · Qué escribe

`## § Conversión`:

| Bloque | Qué lleva |
|---|---|
| **A · El recorrido real** | Dónde entra y dónde se cae, con números si los hay |
| **B · Respuesta** | Qué se automatiza, qué queda humano |
| **C · Seguimiento** | Cuántos toques, cada cuánto, hasta cuándo |
| **D · Closing** | Guiones, las 3 objeciones, cómo se entrena |
| **E · Qué opera ⑧ Community** | El handoff |
| **F · Qué necesita gate** | Lo que habla con el cliente final |

## 7 · Checklist

- [ ] El plan es **Accelerate o Compound**
- [ ] Se **mapeó dónde se pierde** antes de automatizar
- [ ] Hay respuesta para **fuera de hora**
- [ ] El seguimiento tiene **cantidad, frecuencia y final**
- [ ] Las **3 objeciones** tienen respuesta escrita
- [ ] **Todo lo automático que le habla al cliente final tiene gate**
