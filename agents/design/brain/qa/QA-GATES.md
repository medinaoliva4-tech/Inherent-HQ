## D2 — Briefs
- [ ] Un brief por cada pieza no bloqueada

- [ ] El **mensaje único** es una sola oración. Si trae dos ideas → se devolvió
- [ ] La **jerarquía tiene exactamente 3 niveles**, los tres nombrados por Creative
- [ ] 🛑 **Diseño no reordenó los niveles.** Si no entraban, se propuso y se preguntó (`⚠️ OBSERVADO`)
- [ ] El nivel 1 gana peso en **al menos dos** de: tamaño, contraste, área, posición

- [ ] Máximo **1 color de acento**, marcando **una** cosa

## D3 — Composición
- [ ] La pieza se compuso **en gris** antes de aplicar color
- [ ] Hay **un** punto focal, en tercios o centro óptico — no en el centro geométrico por default
- [ ] El nivel 1 pesa ≥2x el nivel 2
- [ ] Hay al menos 8% del alto del formato como aire en el borde con texto
- [ ] La dirección de lectura está declarada (Z / F / vertical)
- [ ] Todo alineado a la grilla; los márgenes del sistema respetados
- [ ] **TEST MINIATURA** al 10% → SÍ
- [ ] **TEST GRIS** → SÍ
- [ ] **TEST ATENCIÓN** — lo primero que se ve es el nivel 1 del brief → SÍ
- [ ] Si algún test dio NO → se volvió a D2 y se cambió el componente (🛑 no se arregló en D4)
- [ ] Se contestaron las 3 preguntas de craft (dónde va la atención 1º, 2º, qué se pierde)
- [ ] Si es carrusel: portada autosuficiente · continuidad entre slides · quiebre en la penúltima
- [ ] Si es seamless: elementos que **cruzan** las guías, no cortados justo sobre ellas

## D5 — Construcción en Figma con Figwright
- [ ] La ruta visual está **aprobada** (🚦 GATE 2) antes de construir el lote
- [ ] Se corrió **`ping`** y el plugin está conectado
- [ ] Si había más de un archivo abierto, se **reclamó** con `list_files` + `use_file`
- [ ] Se leyó el entorno antes de crear nada: `get_variable_defs` · `scan_components` · `get_styles` · `get_fonts`
- [ ] Ningún valor fue inventado — cada uno traza al archivo, al sistema D0 o a la escala de 8pt
- [ ] Los componentes de pieza están como `COMPONENT` con `VARIANTS` por formato — no copiados y pegados
- [ ] Las piezas son `INSTANCE` con `set_instance_properties`, no duplicados sueltos
- [ ] Auto layout en todo lo que tiene relación estructural; `x`/`y` solo para colocar el frame
- [ ] Tamaños por `set_layout_props` (HUG/FILL/FIXED), no por `resize_nodes`
- [ ] **Cero hex y cero px literales** donde existe token (`bind_variable_to_paint` / `bind_variable_to_node`)
- [ ] 🛑 **Ningún texto quedó en Inter** — `set_text_properties` corrido en todo `TEXT`
- [ ] Énfasis dentro de un texto con `set_text_range`, no en un nodo aparte
- [ ] Nomenclatura `<id_pieza>__<canal>__<formato>` en todos los frames
- [ ] Se validó con `get_screenshot` **por bloque**, no solo al final
- [ ] Se revisó en los screenshots: texto cortado · superposiciones · placeholders · variante equivocada · `empty: true`
- [ ] Las piezas con imagen tienen la imagen **realmente puesta** (no frame en blanco)
- [ ] Si Figwright no está conectado: salió como especificación construible marcada `BLOQUEADO`
