# Capa de ciclo · Guardián — valida piezas y claims

| | |
|---|---|
| **Consume** | `guia-de-marca.md` · `sistema-visual.md` · las piezas de ⑥A y ⑥B · los claims `⏸️` de ④ |
| **Produce** | El veredicto por pieza y la validación de claims. Alimenta la columna de estado del ciclo |

> 🔑 **Esta es la capa que corre todos los meses.** Las capas 0 a 5 corren una vez.

## 1 · Dos trabajos distintos

| | Qué valida | Contra qué |
|---|---|---|
| **Piezas** | Que se vean y suenen de marca | `guia-de-marca.md` y `sistema-visual.md` |
| **Claims** | Que lo que afirmamos se pueda sostener | Evidencia. **Sin evidencia, no sale** |

## 2 · La validación de piezas

**Se revisa cada pieza contra una lista cerrada. Sin opinión.**

| Chequeo | Si falla |
|---|---|
| ¿Usa la paleta, con **un solo acento**? | ↩️ Devuelto a ⑥A / ⑥B |
| ¿Las tipografías son las del sistema, con su peso? | ↩️ Devuelto |
| ¿El texto respeta las **safe zones** del formato? | ↩️ Devuelto |
| ¿Lleva los **activos distintivos** que su formato exige? | ↩️ Devuelto |
| ¿El **primer frame** o la **slide 1** lleva activo? | ↩️ Devuelto |
| ¿El copy respeta los **do's & don'ts** y las palabras prohibidas? | ↩️ Devuelto a ④ |
| ¿Nombra la marca como corresponde? | ↩️ Devuelto a ④ |
| **Logo tapado: ¿se reconoce?** | ↩️ Devuelto con la razón |

> 🛑 **Se devuelve con el motivo escrito y la regla que incumple.** *«No me gusta»* no es un
> motivo: **si no se puede citar una regla, la pieza pasa** — y la regla que falta se anota para
> `br-loop`.

## 3 · La validación de claims

**④ marca `⏸️ PENDIENTE APROBACIÓN` todo lo que afirme un resultado, un número o una
comparación. Acá se resuelve.**

| Veredicto | Cuándo |
|---|---|
| ✅ **Validado** | Hay evidencia, y está citada con fuente |
| 🔄 **Reformulado** | Se puede decir, pero de otra forma. Se escribe la versión que sí |
| 🛑 **Rechazado** | No hay evidencia. **No sale** |

| Tipo de claim | Qué evidencia necesita |
|---|---|
| Un número | La fuente del dato, con fecha |
| Un resultado | El caso, con permiso del cliente para contarlo |
| Una comparación | 🔴 **Escala a Allan.** Comparar con competidores tiene riesgo legal |
| *«El mejor»*, *«el único»*, *«el líder»* | 🛑 **Rechazado por defecto**, salvo prueba |

> ⚠️ **Sin fuente va como `[dice el cliente, sin verificar]` o `⚠️ SIN DATOS`. Nunca se
> inventa.**

## 4 · Qué NO hace el guardián

- **No arregla la pieza.** Devuelve a quien la hizo
- **No reescribe el copy.** Eso es ④
- **No frena un ciclo entero** por una pieza. Devuelve la pieza, el resto sigue
- **No impone gusto.** Solo reglas escritas

## 5 · Checklist

- [ ] Todas las piezas del ciclo se revisaron — **sin muestreo**
- [ ] Cada devolución cita **la regla** que incumple
- [ ] Todos los claims `⏸️` tienen veredicto
- [ ] Ningún claim salió **sin fuente**
- [ ] Las comparaciones con competidores **se escalaron**
- [ ] Las reglas que faltaban quedaron anotadas para `br-loop`
