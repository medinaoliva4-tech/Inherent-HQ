# Capa 3 · Sistema visual — con valores, no adjetivos

| | |
|---|---|
| **Consume** | § Territorio y personalidad **con GATE 1** · bloques 5 y 6 del brief de ② |
| **Produce** | **`sistema-visual.md`** — el documento que abren ⑥A y ⑥B para ejecutar |

> 🔑 **La prueba de esta capa:** ¿puede ⑥A producir 100 estáticos con esto, sin preguntar nada?
> Si hace falta criterio en cada pieza, no es sistema.

## 1 · Color — cada uno con su rol

**No es una paleta bonita: es un reparto de trabajo.**

| Rol | Cuántos | Para qué |
|---|---|---|
| **Base** | 1 | El fondo del 80% de las piezas |
| **Tinta** | 1 | El texto. Contraste verificado contra la base |
| **Acento** | 1 | Lo que lleva la mirada. **Uno solo** |
| **Apoyo** | 1-2 | Fondos secundarios, bloques |

**Cada color va con su hex**, y el acento con **dónde se usa y dónde no**.

> 🛑 **Dos acentos son cero acentos.** Si todo resalta, nada resalta.
> ⚠️ **El contraste texto/fondo se verifica**, no se asume.

## 2 · Tipografía — con peso, tamaño y uso

| Nivel | Fuente | Peso | Tamaño | Dónde se usa |

| **Título** | | | | |

| Regla | Por qué |
|---|---|

| **La fuente tiene que estar disponible** | Si ⑥A no la puede usar, no existe |

## 3 · Composición

| | Qué se define |
|---|---|
| **Grilla** | Columnas y canaletas |
| **Márgenes** | En % del lado corto, para que escale entre formatos |
| **Safe zones** | Dónde **nunca** va texto: barras de UI, zona del CTA, pulgar |
| **Jerarquía** | Qué se lee primero, segundo, tercero |
| **Densidad** | Cuánto espacio vacío. **Es donde más se nota el territorio** |

## 4 · Imagen — foto o ilustración

**Se decide una ruta principal y se escribe qué la define.**

| Si es… | Se define |
|---|---|
| **Foto** | Luz, encuadre, qué se ve y qué no, con o sin gente, pose o natural |
| **Ilustración** | Estilo, grosor de línea, relleno, paleta propia |

> ⚠️ **La ruta tiene que ser sostenible.** Si el cliente graba una vez al mes, el sistema no
> puede depender de foto nueva cada semana — se diseña con banco y con lo que da la sesión del mes.
> ⛔ **No se genera imagen con IA:** no hay herramienta.

## 5 · Movimiento — lo que ⑥B necesita

**El sistema visual no termina en el estático.**

| | Qué se define |
|---|---|
| **Cómo entra el texto** | Una sola forma. No cinco animaciones distintas |
| **Ritmo** | Corte rápido o plano sostenido. Coherente con la personalidad |
| **Subtítulos** | Fuente, tamaño, posición, fondo. **Siempre dentro de la safe zone** |
| **El cierre** | Cómo termina toda pieza de video. Es activo distintivo |

## 6 · Qué escribe

**`sistema-visual.md`** — el documento ejecutable:

| Sección | Qué lleva |
|---|---|
| **§ Color** | Tabla con rol, hex, dónde se usa y dónde no |
| **§ Tipografía** | Tabla con fuente, peso, tamaño, uso. Y la alternativa |
| **§ Composición** | Grilla, márgenes, safe zones, jerarquía, densidad |
| **§ Imagen** | La ruta y sus reglas |
| **§ Movimiento** | Entrada de texto, ritmo, subtítulos, cierre |
| **§ Qué está prohibido** | Las cosas que rompen el sistema |

## 7 · Checklist

- [ ] Cada color tiene **hex y rol**
- [ ] Hay **un solo acento**
- [ ] El **contraste** texto/fondo está verificado
- [ ] Máximo **2 familias** tipográficas, y están disponibles
- [ ] Las **safe zones** están definidas por formato
- [ ] La ruta de imagen es **sostenible** con lo que el cliente tiene
- [ ] El **cierre de video** está definido
- [ ] Todo son **valores**, no adjetivos
