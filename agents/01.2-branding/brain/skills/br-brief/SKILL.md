# Capa 0 · Brief — qué decidió ② y qué toca resolver

| | |
|---|---|
| **Consume** | `brand-brief.md` de ② Estrategia · § La capacidad de ① Comprensión · el plan contratado |
| **Produce** | La sección **§ El brief** de `guia-de-marca.md` |

## 1 · Los 8 bloques de ② — se verifican uno por uno

| # | Bloque | Si falta |
|---|---|---|
| **1** | **Tipo de marca** — rebelde / formal / premium / local, con su por qué | 🛑 BLOQUEADO |
| **2** | **Audiencia objetivo** | 🛑 BLOQUEADO |
| **3** | **Posicionamiento** — territorio · enemigo · idea madre | 🛑 BLOQUEADO |
| **4** | **Código saturado** — qué estilo repite la categoría | 🛑 BLOQUEADO |
| **5** | **Dirección visual** — hacia dónde vamos y por qué | 🛑 BLOQUEADO |
| **6** | **Referencias** — incluido el robo de adyacencia | 🟡 Se puede construir |
| **7** | **Voz de marca** | 🛑 BLOQUEADO |
| **8** | **Dónde vive** | 🛑 BLOQUEADO |

🛑 **Ningún bloque se completa por inferencia.** Si falta, se pide a ② Estrategia.

## 2 · La separación que ordena todo

**Cada bloque trae dos partes. Acá se separan explícitamente:**

| | |
|---|---|
| **Lo que ② decidió** | Es **restricción**. No se discute, no se mejora, no se reinterpreta |
| **Lo que ②B resuelve** | Es el trabajo de este departamento |

> 🛑 **Si al leer el brief aparece que la dirección está mal, se devuelve a ②** con el problema
> escrito. **No se corrige acá en silencio.**

## 3 · El techo de realidad

**El sistema tiene que ser sostenible con lo que el cliente tiene.**

| Chequeo | Si no da |
|---|---|
| ¿Con qué produce imágenes? | Si no hay fotógrafo, **el sistema no puede depender de foto propia** |
| ¿Cada cuánto puede grabar? | Un sistema que necesita material nuevo semanal no sirve si graba una vez al mes |
| ¿Quién va a ejecutar esto? | Si lo ejecuta ⑥A con agentes, el sistema tiene que ser **ejecutable sin criterio** |
| ¿Tiene activos previos que respetar? | Se declaran. **Cambiarlos es una decisión, no un descuido** |

## 4 · La profundidad según el plan

| | 🟦 Ignite | 🟪 Accelerate | 🟨 Compound |
|---|---|---|---|
| **Qué se hace** | **Se construye la marca completa** | Se evoluciona | Se sistematiza |
| Activos distintivos | 3 a 5 | + activos para pauta | + guía operable por terceros |
| Entregables | `guia-de-marca.md` + `sistema-visual.md` | + variantes para ⑩ Ads | + manual para que lo use un tercero |

## 5 · Qué escribe

`## § El brief` dentro de `guia-de-marca.md`:

| Bloque | Qué lleva |
|---|---|
| **A · Contexto cargado** | Los 8 bloques con su estado y **ruta** |
| **B · Lo que ② decidió** | Restricciones, literales |
| **C · Lo que ②B resuelve** | La lista de trabajo de este ciclo |
| **D · El código saturado** | Qué repite la categoría, y **hacia dónde vamos** |
| **E · El techo de realidad** | Qué puede sostener el cliente |
| **F · Lo que ya existe** | Activos previos, y si se respetan o se cambian |

## 6 · Checklist

- [ ] Los **8 bloques** están presentes y citados con ruta
- [ ] Lo que ② decidió está separado de lo que ②B resuelve
- [ ] El **código saturado** está escrito, y la dirección contraria también
- [ ] El techo de realidad está declarado
- [ ] Los activos previos están listados, con la decisión de respetarlos o no
