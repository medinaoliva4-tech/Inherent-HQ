## Convenciones de marcado

*(las mismas que Strategy — un solo sistema para todo el repo)*

| Marca | Significado |
|---|---|
| 🟢 | Convención / patrón confirmado — 3+ fuentes independientes |
| 🟡 | Señal a confirmar — 1-2 fuentes |
| ⚪ | Hueco / ruido — sin repetición |
| ⚠️ SIN DATOS | Falta el dato. Se nombra qué falta y cómo conseguirlo |
| `[percepción del cliente, no verificado]` | Lo dijo el cliente, no está comprobado |
| `[generado]` | Asset generado por IA, no es referencia real de otra marca |
| BLOQUEADO | No se puede avanzar. Se nombra qué desbloquea |
| PENDIENTE | Se puede avanzar, falta completar |

**Nunca se borra una sección de la plantilla.** Si no aplica, se marca `N/A — [por qué]`.

## Reglas de especificación

| Mal | Bien |
|---|---|
| "un gris oscuro" | `#0F1115` |
| "una sans moderna" | `Inter Tight SemiBold 32/36, tracking -2%` |
| "mucho aire" | `margen mínimo 64px · espacio en blanco ≥ 40% del área` |
| "fotos lindas" | `plano medio · luz lateral natural · sin flash directo · preset X` |
| "se siente premium" | `un solo foco por pieza · máximo 6 palabras en cover · sin marcos` |

> Si un diseñador que nunca habló con el cliente no puede ejecutarlo sin preguntar, la
> especificación no está terminada.
