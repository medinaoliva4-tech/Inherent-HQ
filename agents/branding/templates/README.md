## Convenciones de marcado

*(las mismas del repo — un solo sistema para todos los departamentos)*

| Marca | Significado |
|---|---|
| 🟢 | Convención / patrón confirmado — 3+ fuentes independientes |
| 🟡 | Señal a confirmar — 1-2 fuentes |
| ⚪ | Hueco / ruido — sin repetición |
| ⚠️ SIN DATOS | Falta el dato. Se nombra qué falta y cómo conseguirlo |
| `[percepción del cliente, no verificado]` | Lo dijo el cliente, no está comprobado |
| `[asset generado]` | Generado por IA, no es referencia real de otra marca |
| BLOQUEADO | No se puede avanzar. Se nombra qué desbloquea |
| PENDIENTE | Se puede avanzar, falta completar |

**Nunca se borra una sección de la plantilla.** Si no aplica, se marca `N/A — [por qué]`.

## Qué se especifica y qué no

| ✅ Branding especifica | 🛑 Branding NO especifica — es de ⑥A Diseño |
|---|---|
| `#0F1115` · `Inter Tight` · `pesos 400/700` | `32/36px, tracking -2%` |
| "curvas suaves, espacio en blanco protagonista" | `margen 64px · grilla de 4 columnas` |
| "luz natural, plano medio, sin flash directo" | el crop exacto de la story |
| "máximo 3 niveles de jerarquía" | qué tamaño tiene cada nivel |
| el piso de contraste (4.5:1) | la matriz medida par por par |

> Si un diseñador tiene que preguntarte **la dirección**, la guía no está terminada.
> Si te pregunta **un margen**, no es tu problema: es su oficio.
