# MÉTODO INHERENT — Branding

Cómo Inherent convierte una estrategia aprobada en una identidad de marca aplicable.

**Secuencial.** Ninguna capa arranca sin el output de la anterior. Si falta un input, se bloquea:
no se improvisa el faltante.

**El principio que ordena todo:** una marca no es un logo. Es todo lo que una persona percibe de
un negocio — cómo habla, cómo se ve, qué promete, qué experiencia da y cómo hace sentir. El
branding construye esa percepción **a propósito**, para que deje de ser accidente.

---

## Las 3 alturas

```
HEREDAR      ¿Qué ya está decidido y qué existe hoy?         → B0-B1
DEFINIR      ¿Qué es esta marca y cómo se comporta?          → B2-B3
FORMALIZAR   ¿Cómo se ve, se aplica y se defiende?           → B4-B6
```

**Regla de altura:** nunca contestes una pregunta de Formalizar con información de Heredar.
Un moodboard no es una auditoría. Una paleta no es una personalidad.

---

## El mapa completo — 7 capas

| Capa | Nombre | Pregunta | Output |
|---|---|---|---|
| **B0** | Herencia y encuadre | ¿Con qué llegamos y dónde tiene que vivir esta marca? | encuadre en sesión |

# CAPA B0 — HERENCIA Y ENCUADRE
### ¿Con qué llegamos y dónde tiene que vivir esta marca?

No produce archivo. Produce el **encuadre declarado en sesión** que habilita todo lo demás.

### B0.1 — Insumos de Strategy

| Campo que heredás | De dónde | Qué condiciona en Branding |
|---|---|---|
| Territorio (**es / no es**) | `posicionamiento.md` 3 | La dirección visual completa |
| Enemigo declarado | `posicionamiento.md` 3.a-b | El punto de vista y el contraste estético |
| Mecanismo único | `posicionamiento.md` 3.c | Qué se demuestra visualmente |
| Promesa + RTBs | `posicionamiento.md` 3 | El sistema verbal y la jerarquía de mensaje |
| Objeciones literales | `posicionamiento.md` 3 | Qué tiene que desarmar la identidad |
| Activos distintivos | `posicionamiento.md` 5 | Qué se conserva, qué se codifica, qué se construye |
| Arquetipo de empresa (1-11) | `nucleo.md` E | El **modo de marca** y los puntos de contacto que importan |
| Restricciones reales | `nucleo.md` D | Cuánta identidad se puede sostener |
| Saturación de media | `ingenieria-inversa.md` 1.3 | El punto de partida de la auditoría visual |

> Si alguno de los campos ✅ del `AGENT.md` no existe → **BLOQUEADO**. Ver `PROCESS.md`.

### B0.2 — Insumos del cliente

Todo lo que exista: logo y sus archivos fuente, manual viejo, tipografías con licencia, banco de
fotos, feed actual, web, packaging, presentaciones, señalética. **Y las referencias** — las cuentas
de Instagram o marcas que el cliente señala como aspiracionales.

Cada referencia se registra con **URL + fecha + qué ve el cliente ahí**. La lectura del cliente es
dato, no verdad: *"me gusta porque se ve premium"* se anota como
`[percepción del cliente, no verificado]` y se descompone en B1.4.

### B0.3 — Superficie de marca

Dónde tiene que funcionar esta identidad. Sin esto, el sistema se diseña para el vacío.

| Dimensión | Qué se declara |
|---|---|
| Canales digitales | IG, TikTok, YouTube, web, email, WhatsApp, marketplace |
| Físico | local, señalética, packaging, uniforme, vehículo, merch |
| Impresión | ¿hay? → entonces hay CMYK/Pantone y hay que verificar la conversión |
| Comercial | propuesta, presupuesto, factura, contrato |
| Quién ejecuta | diseñador interno / freelance / el dueño en Canva / Production |
| Capacidad real | cuántas piezas por semana puede sostener ese ejecutor |

> **Regla de viabilidad.** Un sistema que exige un diseñador senior no sirve para un cliente que
> publica desde el celular. La identidad se diseña **para quien la va a ejecutar**, no para el
> portfolio. Si el sistema no cabe en la capacidad, se simplifica acá — no se descubre en B6.

### B0.4 — Modo de marca

El arquetipo de empresa (1-11) dice **cómo gana el negocio**. El modo de marca dice **con qué
registro se construye la identidad**. Son ejes distintos y los dos mandan.

`Formal / Confianza` · `Rebelde / Cultural` · `Premium` · `Local` · `Técnico` · `Lifestyle`

Se elige **uno dominante + un modificador opcional**. Ficha completa y mapeo contra los 11
arquetipos: `playbooks/MODOS-DE-MARCA.md`.

> Un estudio de abogados no copia la provocación de una marca de bebidas. Copia el **pensamiento
> estratégico**, no el tono. Confundir eso es el error más caro del departamento.

### Declaración de cierre de B0

```
ENCUADRE — Cliente: [x] · Arquetipo: [NN] · Modo de marca: [x + modificador]
Territorio: [es / no es] · Enemigo: [x]
Superficie: [canales · físico · impresión sí/no] · Ejecutor: [x] · Capacidad: [x/semana]
Assets existentes: [x] · Referencias del cliente: [n, con URL]
→ PASS | BLOQUEADO: [qué falta]
```

# CAPA B1 — AUDITORÍA Y SATURACIÓN VISUAL
### ¿Qué tiene hoy y cómo se ve la categoría?

**Esta capa no decide.** Igual que la Capa 1 de Strategy: organiza lo que existe. Si escribís
*"por lo tanto deberíamos usar verde"*, te saliste del rol.

Playbook operativo: `playbooks/AUDITORIA-VISUAL.md`.

### B1.1 — Inventario de lo que existe

| Elemento | Existe | Estado | Archivo fuente | Consistencia observada |
|---|---|---|---|---|
| Logo y variaciones | sí/no | sirve / a refinar / a rehacer | .ai/.svg/ninguno | dónde se rompe |
| Paleta | | | | |
| Tipografías (+ licencia) | | | | |
| Estilo fotográfico | | | | |
| Plantillas / covers | | | | |
| Tono verbal | | | | |

**Regla de conservación.** Un activo que la audiencia ya reconoce es capital acumulado. No se tira
porque no nos guste: se refina. Las marcas fuertes **evolucionan con ajustes pequeños**; cambiar
todo de golpe quema reconocimiento que costó años. Se rehace solo si contradice el territorio o
falla la prueba del logo tapado.

### B1.2 — Prueba del logo tapado (propia)

Tomar 6 piezas reales publicadas por la marca. Tapar el logo.

| Pieza | ¿Se reconoce? | ¿Por qué sí o por qué no? |
|---|---|---|

Diagnóstico: `reconocible` / `reconocible por un solo elemento (frágil)` / `no reconocible`.

### B1.3 — Saturación visual de la categoría

**Mínimo 10 marcas** de la categoría, descompuestas en **8 capas visuales**:

| # | Capa | Qué se registra |
|---|---|---|
| 1 | Color dominante | HEX aproximado + rol |
| 2 | Tipografía | serif / sans / display / mono · peso · tracking |
| 3 | Composición | centrada / grilla / asimétrica · densidad |
| 4 | Fotografía | producto / persona / lugar / stock · luz · tratamiento |
| 5 | Densidad de texto | cuánto texto en pantalla, tamaño en thumbnail |
| 6 | Elementos gráficos | iconos, texturas, marcos, gradientes |
| 7 | Formato de portada | ¿hay sistema de covers? ¿cuál? |
| 8 | Registro verbal | cómo titulan, qué prometen, qué palabras repiten |

Y el cruce:

| Lectura | Marca | Qué significa |
|---|---|---|
| Lo usan **todos** (3+) | 🟢 convención | Usarlo = invisibilidad. Romperlo = riesgo de ilegibilidad |
| Lo usa **uno fuerte** | 🟡 territorio ocupado | Ir ahí es pelear contra memoria instalada |
| No lo usa **nadie** | ⚪ hueco | Candidato — hay que verificar por qué está vacío |

> **Un hueco vacío no siempre es una oportunidad.** A veces está vacío porque no funciona en esa
> categoría. Antes de tomarlo, nombrá la hipótesis de por qué nadie lo ocupa.

### B1.4 — Referencias

Las del cliente + las que encuentres. Cada una se **descompone en principio**, no se guarda como
imagen bonita.

| Referencia | URL | Categoría | Qué se toma (**el principio**) | Qué NO se toma (**la forma**) |
|---|---|---|---|---|

> **Referencia ≠ réplica.** Se toma *"el espacio negativo hace que el producto se sienta
> intencional"*. No se toma *"fondo beige con el producto centrado"*. Si la traducción termina
> pareciéndose a la referencia, falló el filtro.

Las referencias **fuera de categoría** suelen valer más que las de adentro: son la forma más
directa de traer un código que la categoría todavía no tiene.

### B1.5 — Hallazgos

Cierre en 5-8 hallazgos marcados `🟢 / 🟡 / ⚪`, cada uno con conteo de fuentes. **Ninguno
recomienda nada.** Terminan en *"la categoría hace X"*, nunca en *"deberíamos hacer Y"*.

# CAPA B2 — CONCEPTO Y PERSONALIDAD
### ¿Qué es esta marca y cómo se comporta?

El corazón del departamento. Sin esto, todo lo visual es decoración.

### B2.1 — Idea madre

Una frase. El norte al que se vuelve cuando no sabés qué color usar, qué tono elegir o cómo
responder un mensaje.

**No es un slogan** (eso es de Creative) ni la promesa (eso es de Strategy). Es el concepto que
gobierna las decisiones internas.

**Prueba de la idea madre:** poné tres decisiones de diseño pendientes al lado. Si la idea no
resuelve al menos dos, no es una idea madre — es una frase linda.

| Ejemplo de idea madre | Qué resuelve |
|---|---|
| *"Nada se interpone"* | Composición limpia, sin marcos, sin ruido gráfico, copy corto |
| *"Salud sin miedo"* | Fotos de personas relajadas, sin instrumental, sin blanco clínico |
| *"No negocies tu mañana"* | Luz natural, ritual, silencio visual, nada de ofertas gritadas |

### B2.2 — Punto de vista

Una marca sin opinión es invisible. El punto de vista **sale del enemigo declarado en Capa 4 de
Strategy** — acá se convierte en algo que la marca puede sostener en público.

| | |
|---|---|
| **Qué defendemos** | |
| **Qué rechazamos** | |
| **La verdad incómoda que podemos sostener** | |
| **A quién repele esto** | *(y está bien)* |

> Una buena marca **atrae a quienes piensan igual y repele a quienes no encajan**. Si no repele a
> nadie, no tiene punto de vista.

### B2.3 — Verdad emocional no dicha

Qué siente el comprador y no dice en voz alta. Sale de las objeciones literales de Strategy y de
la audiencia real (`ingenieria-inversa.md` 1.5).

> *El cuidado del cabello no es verse bien: es una declaración personal.*
> *Ir al dentista no es miedo al dolor: es miedo a que te juzguen la boca.*

### B2.4 — Personalidad

**3-5 rasgos.** Cada uno con **contraste** y definido por **comportamiento observable**, no por
adjetivo.

| Rasgo (con contraste) | Cómo se ve | Cómo NO se ve |
|---|---|---|
| *Directa pero no agresiva* | Frases cortas, sin rodeos, una idea por pieza | Mayúsculas, signos de exclamación, urgencia falsa |

**Por qué el contraste.** *"Elegante"*, *"moderna"* y *"minimalista"* los dice todo el mundo — no
definen nada. La tensión sí: `formal pero humano` · `premium pero simple` · `local pero sofisticado`
· `técnico pero fácil` · `serio pero no aburrido`. **Una marca sin contraste se olvida rápido.**

**Anti-rasgos.** Los tres adjetivos que la marca nunca debe provocar.

### B2.5 — Qué NO es la marca

Definir el rechazo antes que la forma. Sale de *"no es"* del territorio y del enemigo.

- Qué estética rechazamos y por qué
- Qué error común de la categoría no vamos a repetir
- Qué tipo de cliente no queremos atraer
- Qué recurso visual está prohibido desde el día uno

### B2.6 — Sensación objetivo

| | |
|---|---|
| **Qué debe SENTIR** | |
| **Qué debe PENSAR** | |
| **Qué debe RECORDAR** | |

Distinguí **reconocible** (*"sé quién es esta marca"*) de **recordable** (*"esta marca me dejó
algo"*). El sistema visual persigue lo primero; el concepto persigue lo segundo. Se necesitan los dos.

🚦 **GATE B1 — la plataforma la aprueba un humano.** Nada visual arranca antes.

# CAPA B3 — SISTEMA VERBAL / TONO DE VOZ
### ¿Cómo habla?

El tono no se describe, **se demuestra reescribiendo texto real del cliente**.

### B3.1 — Registro

Posición en cada eje, con justificación contra un rasgo de personalidad:

```
formal      ├────●─────┤  coloquial
serio       ├──●───────┤  divertido
distante    ├──────●───┤  cercano
sobrio      ├───●──────┤  intenso
técnico     ├─────●────┤  simple
```

### B3.2 — Léxico

| | |
|---|---|
| **Palabras que sí** | el vocabulario propio, 10-20 |
| **Palabras que nunca** | incluidas las muletillas de la categoría detectadas en B1.3 |
| **Cómo nombramos las cosas** | glosario propio: cómo llamamos al producto, al cliente, al proceso |

> Si tu categoría entera dice *"calidad"*, *"atención personalizada"* y *"soluciones a medida"*,
> esas tres palabras entran directo a la lista de prohibidas.

### B3.3 — Construcción

| Elemento | Regla |
|---|---|
| Titulares | estructura, longitud máxima, ¿pregunta o afirmación? |
| Apertura recurrente | ¿hay una forma fija de empezar? (activo distintivo verbal) |
| Longitud de párrafo | |
| Puntuación | ¿punto final en titulares? ¿signos de exclamación? |
| Mayúsculas | |
| Emojis | sí / no / cuáles / dónde |
| Números y datos | cómo se escriben |
| CTA | las 3-5 formas válidas, con su intensidad |

### B3.4 — Mensaje por temperatura

Hereda las 4 temperaturas de `estrategia-de-contenido.md` (Capa 6 de Strategy). **La promesa nunca
cambia** — cambia cómo se dice.

| Temperatura | Qué se dice | Qué NO se dice |
|---|---|---|
| Frío | | |
| Tibio | | |
| Caliente | | |
| Cliente | | |

### B3.5 — Tono por punto de contacto

El registro se **modula**, no se reemplaza: caption de IG, story, web hero, WhatsApp, presupuesto,
email, respuesta a una reseña mala, atención a un reclamo.

> La marca tiene que sentirse igual en Instagram, en un presupuesto y en un WhatsApp. **Esa
> coherencia es lo que construye confianza — y la confianza es lo que justifica el precio.**

### B3.6 — Antes / después

**Mínimo 5 ejemplos** de texto real del cliente reescrito. Esto es la prueba del entregable: si no
podés reescribir, el tono todavía no existe.

| Antes (real) | Después | Qué cambió y por qué |
|---|---|---|

# CAPA B4 — DIRECCIÓN VISUAL
### ¿Qué estilo traduce ese concepto?

### B4.1 — Los 6 ejes estéticos

Cada posición se justifica **dos veces**: contra el concepto (B2) y contra el mapa de saturación
(B1.3). Una posición que no contrasta con la categoría produce una marca correcta e invisible.

| Eje | Qué decide |
|---|---|
| **Bold ↔ Elegante** | El volumen de la marca |
| **Minimalista ↔ Expresivo** | Cuánto ruido se permite |
| **Serio ↔ Energético** | El pulso |
| **Premium ↔ Accesible** | La señal de valor |
| **Tipografía protagonista ↔ Símbolo protagonista** | Dónde vive el reconocimiento |
| **Curva / orgánico ↔ Ángulo / técnico** | La forma base |

**Sobre el último eje.** Las curvas se leen naturales, suaves, cómodas. Los ángulos duros se leen
precisos, técnicos, agresivos. No es decoración: es la lectura más rápida que hace el cerebro sobre
una marca.

### B4.2 — Las direcciones

**1 o 2 direcciones. Nunca 5.** Cinco direcciones no son generosidad, son falta de criterio: le
pasan la decisión al cliente.

Cada dirección lleva:

| | |
|---|---|
| **Nombre** | corto, memorable |
| **Principio en una frase** | |
| **Posición en los 6 ejes** | |
| **Moodboard** | tipografía · color · aplicaciones/packaging · estilo gráfico · referencias de logo · sensación general |
| **A qué parte del territorio responde** | cita literal del `posicionamiento.md` |
| **Qué convención de categoría rompe** | del mapa B1.3 |
| **Riesgo** | qué puede salir mal |

Todas las imágenes del moodboard con **fuente y URL**.

### B4.3 — Filtro de distintividad

Heredado de la Capa 4 de Strategy, aplicado ahora a lo visual:

| Filtro | Pregunta | Pasa |
|---|---|---|
| **Distinctiveness** | ¿Puede sentirse inequívocamente como esta marca? | ✅/❌ |
| **Novelty** | ¿Hay algo que la gente no vea todos los días en esta categoría? | ✅/❌ |
| **Relevance** | ¿Esa novedad importa para esta audiencia y este objetivo? | ✅/❌ |

**Prueba del logo tapado, aplicada a la dirección:** maquetá 3 piezas de muestra sin logo y ponelas
al lado de 3 piezas de competidores. ¿Se distinguen?

Si falla **Distinctiveness** → es un copycat correcto. Si falla **Relevance** → es diferenciación
random. En los dos casos: **volvé a B4.1 y movés los ejes. No se fuerza.**

### B4.4 — Elección

La dirección elegida, y **por qué se descarta la otra** — por escrito. El descarte documentado es
lo que evita volver a discutirlo en tres meses.

🚦 **GATE B2 — el gate más importante del departamento.** Todo B5 y B6 dependen de esto.

# CAPA B5 — SISTEMA VISUAL
### ¿Con qué elementos y valores exactos?

Acá se diseña **un sistema, no un logo**. Valores concretos siempre: `#0F1115`, no *"gris oscuro"*.

Playbooks: `playbooks/COLOR.md` · `playbooks/TIPOGRAFIA.md` · `playbooks/COMPOSICION-Y-ESTETICA.md`.

### B5.1 — Logo

Principal · horizontal · vertical · isotipo · monocromo · versión para fondo oscuro.
Área de respiro · tamaño mínimo (px y mm) · usos prohibidos · qué hacer sobre foto.

> **No se pone el logo en todo.** El objetivo es que te reconozcan **sin** el logo. Si necesitás
> ponerlo gigante y repetido, el sistema visual no es suficientemente fuerte.

Si el logo no se rediseña: se documenta el existente con sus reglas. Eso también es entregable.

### B5.2 — Color

| Rol | Nombre | HEX | RGB | CMYK / Pantone | Uso |
|---|---|---|---|---|---|
| Primario | | | | | |
| Secundario | | | | | |
| Acento | | | | | |
| Neutros (3-5) | | | | | |
| Fondo claro / oscuro | | | | | |
| Semánticos (éxito/error) | | | | | |

Además:
- **Proporción de reparto** — ej. `60 neutro / 30 primario / 10 acento`
- **Contraste verificado** — ratio de cada combinación texto/fondo, mínimo AA (4.5:1 texto normal)
- **Combinaciones prohibidas**
- **Justificación** — contra el mapa de saturación, **no** contra psicología del color
- Si hay impresión: **la conversión RGB→CMYK se verifica**, no se asume. Un HEX puede no tener
  equivalente exacto en tinta.

### B5.3 — Tipografía

**1-2 familias. Tres solo con criterio probado.**

| Rol | Familia | Peso | Tamaño | Interlineado | Tracking |
|---|---|---|---|---|---|
| Display | | | | | |
| Título | | | | | |
| Subtítulo | | | | | |
| Cuerpo | | | | | |
| CTA / botón | | | | | |
| Dato / caption | | | | | |

- **Contraste de pesos:** si usás `Light`, saltá a `Medium` o `Bold`. `Light + Regular` no es
  contraste, es error.
- **Licencia** declarada (desktop / web / app) y **quién la tiene**.
- **Soporte verificado:** `ñ`, tildes, `¿`, `¡`, comillas. Una tipografía sin `ñ` no entra.
- **Alternativa web-safe / fallback** para email y sistemas que no la soportan.

### B5.4 — Composición y grilla

Márgenes · columnas · gutters · jerarquía en 3 niveles · reparto de peso visual · uso de la regla
de tercios · espacio en blanco mínimo · qué se ve primero en cada formato.

> **La composición sostiene todo.** Podés tener buena tipografía, buen color y buenas fotos: si la
> composición está mal, el diseño se cae igual. Componer es decidir con intención qué va, dónde va,
> qué tamaño tiene y cómo se relaciona con lo demás.

### B5.5 — Fotografía e imagen

Sujeto · encuadre · luz · paleta dentro de la foto · dirección de arte · personas (¿reales del
cliente o modelos?) · tratamiento/preset con valores · mezcla de planos (general / medio / detalle)
· qué nunca (stock genérico, sobreedición, HDR, filtros de moda).

> Mientras más artificial se vuelve el mundo, **más valor tiene lo humano**: personas reales,
> procesos reales, decisiones reales. No significa hacerlo mal — significa que se note verdadero.

### B5.6 — Elementos gráficos

Iconos (familia, grosor, esquinas) · patrones · texturas · gradientes · formas · marcos y bordes ·
líneas. Y el **límite**: cuántos elementos por pieza como máximo.

### B5.7 — Motion y ritmo

Velocidad de corte · tipo de transición · animación de texto (entrada/salida/duración) · subtítulos
(tipografía, posición, estilo) · apertura y cierre recurrentes · uso del logo en video.

### B5.8 — Sonido

Si aplica: tipo de música, tempo, voz (género, edad, registro), sonido de marca, silencio.

### B5.9 — Activos distintivos codificados

La Sección 5 de `posicionamiento.md` lista los activos. **Acá se les pone valor concreto.**

| Activo | Estado en Strategy | Especificación en Branding |
|---|---|---|
| Color | a construir | `#E4FF1A` al 10% de reparto, siempre sobre neutro oscuro |
| Formato recurrente | existente | Cover con banda inferior 120px, título en 2 líneas máx |

> Los activos distintivos **se refuerzan con consistencia, no se reinventan cada ciclo**. Un activo
> cambiado a los 6 meses nunca llega a ser activo.

# CAPA B6 — APLICACIONES, REGLAS Y GOBERNANZA
### ¿Cómo vive en cada punto de contacto?

La marca no vive en el manual. Vive en la web, las redes, el equipo, el producto, los presupuestos,
la atención al cliente y la entrega.

### B6.1 — Punto de contacto por punto de contacto

Solo los que se declararon en B0.3. Cada uno:

| | |
|---|---|
| **Qué elementos entran** | |
| **Jerarquía** | qué se ve primero |
| **Especificación** | medidas, márgenes, tamaños de texto |
| **Qué NO se hace acá** | |

Cubrir según superficie: **feed** (post / carrusel / cover de reel) · **stories y highlights** ·
**web** (hero, secciones, botones) · **WhatsApp** (foto de perfil, catálogo, mensajes fijos) ·
**propuesta y presupuesto** · **email** · **packaging** · **local y señalética** · **merch** ·
**presentación comercial**.

### B6.2 — Sistema de portadas

Lo que hace que un feed se reconozca de un scroll. Grilla de la cover, zona segura, cantidad máxima
de palabras, tamaño mínimo legible **en thumbnail**, dónde va el logo (si va).

### B6.3 — Coherencia sin uniformidad

| | |
|---|---|
| **Qué se repite siempre** | lo que construye reconocimiento |
| **Qué puede variar** | el rango permitido |
| **Qué nunca se repite seguido** | mismo encuadre, mismo color dominante o misma cantidad de texto en dos posts consecutivos |

> La consistencia viene del **tratamiento**, no de forzar todo a los colores de marca. Un feed
> donde cada pieza es idéntica no es coherente: es aburrido. Y un sistema que se rompe porque se
> atrasó un post es un sistema frágil — evitá damero, tercios rígidos y ratios fijos.

### B6.4 — Reglas duras

La lista de **nunca**. Corta, concreta, sin explicaciones largas. Es lo que más se consulta.

### B6.5 — Test final de reconocimiento

| Prueba | Criterio | Resultado |
|---|---|---|
| 3 piezas sin logo, mezcladas con 3 de competidores | ¿Se identifican las nuestras? | ✅/❌ |
| Feed a tamaño thumbnail | ¿Se lee el texto? ¿Se distingue el sistema? | ✅/❌ |
| Contraste de cada par texto/fondo | ≥ 4.5:1 | ✅/❌ |
| Pieza en blanco y negro | ¿Sobrevive sin color? | ✅/❌ |
| El ejecutor real arma una pieza siguiendo la guía | ¿Le sale sin preguntar? | ✅/❌ |

**El último ítem es el que define si el entregable está terminado.**

### B6.6 — Gobernanza

Quién aprueba qué · cada cuánto se revisa el sistema (default: **6 meses**, o antes si cambia el
posicionamiento) · cómo se pide una excepción y quién la autoriza · dónde viven los archivos fuente
y las licencias · qué hace que esta guía quede obsoleta.

🚦 **GATE B3 — el `brand-guidelines.md` lo aprueba un humano antes del handoff.**

## Ciclo

```
Strategy Capa 4 aprobada → Branding B0 → … → B6 → handoff
                                              ↓
        Analytics / Capa 8 de Strategy → ¿el sistema se reconoce? ¿se ejecuta?
                                              ↓
                          revisión de B5-B6 (no de B2, salvo que cambie el posicionamiento)
```

**Qué se revisa y cuándo:**

| Cambió | Se re-corre |
|---|---|
| Nada, pasaron 6 meses | B6 (aplicaciones) — chequeo de deriva |
| El ejecutor o la capacidad | B5.4-B6 |
| El territorio o el enemigo | **Todo desde B2** |
| Nuevo canal o punto de contacto | B6.1 |

> Cambiar la identidad cada ciclo destruye lo único que el branding acumula: **reconocimiento**.
> El default es refinar, no reinventar.
