# Modos de Marca — 6 registros de identidad

**Por qué existe esto.** Un estudio de abogados y una marca de bebidas no se construyen igual. El
abogado no copia la provocación: copia el **pensamiento estratégico**. Aplicar el mismo registro a
los dos garantiza que uno de los dos se rompa.

**Qué es y qué no es.** El **arquetipo de empresa** (1-11, de Strategy) dice *cómo gana el negocio*:
motor de demanda, canales, métricas. El **modo de marca** dice *con qué registro se construye la
identidad*: cuánto riesgo tolera, dónde vive el valor percibido, qué recursos puede usar.

Son ejes distintos. Los dos mandan. Se declara **uno dominante + modificador opcional**.

---

## Los 6 modos

### 01 · FORMAL / CONFIANZA
**Para:** abogados, médicos, seguros, bancos, inmobiliaria, B2B, consultoría, educación seria.

| | |
|---|---|
| **Objetivo** | Confianza + autoridad + conversión |
| **Dónde vive el valor** | En la claridad y en la prueba |
| **Recursos válidos** | Claridad, autoridad, transparencia, procesos simples, diseño premium, contenido educativo, lenguaje humano, casos, confianza visual |
| **Recursos prohibidos** | Provocación, memes, stunts, lenguaje callejero, urgencia falsa |
| **Enemigo típico** | El lenguaje diseñado para confundir. La atención fría. La letra chica |
| **Estética** | Ordenada, legible, espaciada. Sans clara + serif de autoridad. Neutros + un acento |
| **Trampa** | Confundir *formal* con *aburrido*. Un abogado puede tener enemigo declarado — *"legal sin confusión"* — sin necesitar un nombre controversial |

### 02 · REBELDE / CULTURAL
**Para:** bebidas, ropa, restaurantes casuales, barberías, suplementos, nightlife, fast food, DTC,
marcas de creador.

| | |
|---|---|
| **Objetivo** | Atención + comunidad + deseo |
| **Dónde vive el valor** | En la pertenencia y en la conversación |
| **Recursos válidos** | Humor, provocación, campañas raras, nombres atrevidos, eventos, merch, stunts, lenguaje coloquial |
| **Recursos prohibidos** | Corporativismo, stock genérico, promesas blandas |
| **Enemigo típico** | El líder dormido. El default aburrido. Lo tradicional |
| **Estética** | Contraste alto, tipografía protagonista, densidad alta o vacío total — nunca el medio |
| **Trampa** | Provocar sin idea madre. La provocación sin concepto se quema en un mes |

### 03 · PREMIUM
**Para:** hoteles, restaurantes finos, joyería, moda, estética, arquitectura, wellness, skincare.

| | |
|---|---|
| **Objetivo** | Valor percibido + aspiración |
| **Dónde vive el valor** | En el detalle, el material y el ritual |
| **Recursos válidos** | Ritual, deseo, silencio visual, fotografía cuidada, materiales, escasez, precio como señal, experiencia |
| **Recursos prohibidos** | Gritar, saturar, descuentos visibles, más de un mensaje por pieza |
| **Enemigo típico** | Lo masivo. Lo apurado. Lo que se ve caro pero no lo es |
| **Estética** | Espacio negativo dominante, tipografía con tracking abierto, paleta corta, un solo foco |
| **Trampa** | **Lo premium no se declara, se percibe.** Si el precio es premium y la web se ve barata, la fricción destruye la promesa antes de la primera venta |

### 04 · LOCAL
**Para:** café, barbería, gym, clínica dental, taller, salón, restaurante de barrio, inmobiliaria local.

| | |
|---|---|
| **Objetivo** | Confianza rápida + recordación local |
| **Dónde vive el valor** | En verse y operar **10 veces mejor que el de la cuadra** |
| **Recursos válidos** | Naming claro, identidad sólida y simple, reseñas, contenido local, oferta simple, fotos reales buenas, WhatsApp bien trabajado, procesos rápidos |
| **Recursos prohibidos** | Sistemas que exigen un diseñador senior. Abstracción que tape qué vendés y dónde estás |
| **Enemigo típico** | El competidor de al lado que no se esfuerza |
| **Estética** | Legible a distancia, funciona impresa y en cartel, sobrevive en una foto de celular |
| **Trampa** | Diseñar para el portfolio y no para quien lo va a ejecutar desde el mostrador |

### 05 · TÉCNICO / UTILITARIO
**Para:** SaaS, herramientas, software factory, logística, industrial, fintech de infraestructura.

| | |
|---|---|
| **Objetivo** | Claridad + credibilidad técnica + adopción |
| **Dónde vive el valor** | En que se entienda rápido y funcione |
| **Recursos válidos** | Datos, diagramas, demos, documentación, precisión, sistema de diseño, consistencia obsesiva |
| **Recursos prohibidos** | Metáforas vagas, ilustraciones genéricas de gente feliz, promesas sin número |
| **Enemigo típico** | La herramienta que promete todo y no hace nada. El vendor lock-in. La complejidad innecesaria |
| **Estética** | Grilla estricta, sans neutra o mono, ángulos, jerarquía marcada, color funcional |
| **Trampa** | Confundir *técnico* con *frío*. La claridad es la calidez de este modo |

### 06 · LIFESTYLE
**Para:** marcas donde el producto es común y lo que se compra es lo que representa. Cruza con
DTC, fitness, café, indumentaria, comunidades.

| | |
|---|---|
| **Objetivo** | Identificación + deseo + repetición |
| **Dónde vive el valor** | En el mundo alrededor del producto, no en el producto |
| **Recursos válidos** | Universo cultural, contenido que expande la idea madre, personas reales, rituales, colaboraciones con significado |
| **Recursos prohibidos** | Hablar solo del producto y sus features |
| **Enemigo típico** | La categoría dormida que vende función y no significado |
| **Estética** | Fotografía de situación por encima de producto en fondo blanco. La marca aparece en la vida, no en el catálogo |
| **Trampa** | Un mundo lifestyle sin producto claro. Si nadie entiende qué vendés, falló |

## Mapeo contra los 11 arquetipos de empresa

Punto de partida, **no regla**. La evidencia del cliente manda sobre la tabla.

| # | Arquetipo (Strategy) | Modo dominante típico | Modificadores frecuentes |
|---|---|---|---|
| 01 | Local Alta Frecuencia | **Local** | Lifestyle · Rebelde |
| 02 | Local Alto Ticket | **Local** | Premium · Formal |
| 03 | Marca Personal / Experto | **Formal** o **Rebelde** según categoría | Lifestyle |
| 04 | E-commerce / DTC | **Lifestyle** | Premium · Rebelde |
| 05 | Servicio Profesional B2B | **Formal** | Técnico |
| 06 | SaaS / Suscripción | **Técnico** | Formal |
| 07 | Infoproducto / Educación | **Rebelde** o **Formal** según promesa | Lifestyle |
| 08 | Marketplace / Plataforma | **Técnico** | Local (si es geográfico) |
| 09 | Hospitalidad / Experiencia | **Premium** | Lifestyle · Local |
| 10 | Institución / Corporativo | **Formal** | Técnico |
| 11 | Media / IP | **Lifestyle** | Rebelde |

**Híbridos.** Se declaran así:
```
Modo dominante: 04 Local
Modificador: 03 Premium (ticket alto y el local es parte de la promesa)
```
El dominante define el registro y los recursos válidos. El modificador define el nivel de acabado.
**Nunca se promedian** — eso produce una marca tibia que no sirve para ninguno de los dos.

---

## Cómo se elige

1. ¿Qué **riesgo** acepta el cliente de esta categoría? *No es lo mismo vender café que cirugía.*
   → mucho riesgo aceptado = Rebelde · poco = Formal
2. ¿Dónde vive la **confianza**? (eje 6 del arquetipo) → persona = Lifestyle/Rebelde ·
   institución = Formal · producto = Técnico/Premium
3. ¿El valor está en el **producto** o en lo que **representa**? → producto = Técnico/Local ·
   representación = Lifestyle/Premium
4. ¿Es **local físico**? → el modo Local entra sí o sí, aunque sea como modificador.

## El principio detrás del modo

> **Un producto común se vuelve deseable cuando la marca cambia la percepción.**
> No siempre hay que cambiar el producto. Un dentista no reinventa la odontología, pero sí puede
> cambiar cómo se siente ir al dentista. Una barbería no reinventa cortar el pelo, pero sí puede
> crear ritual, estética y comunidad.

**Señales de categoría dormida** — donde el modo elegido tiene más upside:
- Todas las marcas comunican igual
- El líder se ve viejo o cómodo
- El producto se compra por necesidad y nadie lo ama
- La categoría da aburrimiento, pena o indiferencia

Si las cuatro dan que sí, hay espacio para entrar con un modo distinto al de toda la categoría.
Eso se verifica en **B1.3**, no se asume.

> **Si competís por precio, sos commodity. Si competís por percepción, sos marca.**
