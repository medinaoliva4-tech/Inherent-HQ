# Playbook — Auditoría y Saturación Visual (Capa B1)

Cómo se hace la ingeniería inversa **visual** de una categoría. Es el equivalente de la Capa 1 de
Strategy, pero mirando forma en vez de mensaje.

🛑 **Esta capa no decide nada.** Termina en mapa. Si aparece un *"por lo tanto"*, salió del rol.

---

## 1 · Inventario propio

Todo lo que la marca ya tiene, con estado honesto.

| Elemento | Existe | Estado | Fuente | Dónde se rompe |
|---|---|---|---|---|
| Logo principal | | sirve / a refinar / a rehacer | .ai .svg .png ninguno | |
| Variaciones del logo | | | | |
| Paleta | | | | |
| Tipografías | | + **licencia** | | |
| Estilo fotográfico | | | | |
| Plantillas / covers | | | | |
| Web | | | | |
| Packaging / físico | | | | |
| Tono verbal | | | | |

**Cómo se declara el estado:**

| Estado | Criterio |
|---|---|
| `sirve` | Es reconocible, aplicable y no contradice el territorio |
| `a refinar` | La idea está, la ejecución no. Proporciones, pesos, consistencia |
| `a rehacer` | Contradice el territorio, es ilegible, o no existe archivo fuente |

> **Regla de conservación.** Un activo que la audiencia ya reconoce es capital acumulado. Las
> marcas fuertes evolucionan con ajustes pequeños — lo familiar bien refinado se siente más premium
> que lo nuevo. Se rehace solo con razón escrita, nunca por gusto.

## 2 · Prueba del logo tapado (propia)

6 piezas reales ya publicadas. Se tapa el logo.

| # | Pieza | ¿Se reconoce? | Por qué |
|---|---|---|---|

**Diagnóstico:**

| Resultado | Significa |
|---|---|
| Reconocible por 2+ elementos | Hay sistema. Se refina |
| Reconocible por 1 solo elemento | Sistema frágil — si ese elemento cambia, desaparece la marca |
| No reconocible | No hay sistema. Hay piezas sueltas |

## 3 · Saturación visual de la categoría

**Mínimo 10 marcas.** Competidores directos de `ingenieria-inversa.md` 1.1 + los líderes de
categoría aunque no compitan localmente.

### Las 8 capas visuales

| # | Capa | Qué se registra |
|---|---|---|
| 1 | **Color dominante** | HEX aproximado, rol, cuánto ocupa |
| 2 | **Tipografía** | serif / sans / display / mono · peso · tracking · ¿protagonista? |
| 3 | **Composición** | centrada / grilla / asimétrica · densidad · márgenes |
| 4 | **Fotografía** | sujeto · luz · tratamiento · ¿stock o propia? |
| 5 | **Densidad de texto** | cuántas palabras en pantalla · ¿legible en thumbnail? |
| 6 | **Elementos gráficos** | iconos · texturas · marcos · gradientes · formas |
| 7 | **Sistema de portadas** | ¿existe? ¿cuál es la fórmula? |
| 8 | **Registro verbal** | cómo titulan · qué prometen · qué palabras repiten |

### La tabla de saturación

Una fila por capa, no por marca:

| Capa | Lo que hacen 3+ | Lo que hace solo 1 fuerte | Lo que no hace nadie |
|---|---|---|---|
| Color | 🟢 | 🟡 | ⚪ |
| Tipografía | | | |
| … | | | |

### Cómo se lee

| Marca | Significa | Decisión que habilita (en B4, no acá) |
|---|---|---|
| 🟢 **convención** (3+) | Es el código de la categoría | Usarlo = invisible · Romperlo = riesgo de ilegibilidad |
| 🟡 **territorio ocupado** (1 fuerte) | Alguien ya lo posee en memoria | Ir ahí es pelear contra recuerdo instalado |
| ⚪ **hueco** (nadie) | Espacio libre | Candidato — **primero hay que explicar por qué está vacío** |

> **Un hueco no siempre es oportunidad.** A veces está vacío porque no funciona: nadie usa
> tipografía manuscrita en fintech porque destruye la credibilidad. Antes de tomar un hueco,
> escribí la hipótesis de por qué nadie lo ocupa. Si la hipótesis es *"porque son todos vagos"*,
> probablemente esté mal.

### El mínimo de ilegibilidad

Hay convenciones que **no se rompen** porque son lo que hace que te entiendan:
la forma reconocible del producto, el código de temperatura en comida, la señalética de seguridad,
la estructura de precio en retail.

**Ser diferente sin dejar de ser entendible.** Si el empaque parece perfume pero sigue leyéndose
como lo que es, funciona. Si nadie entiende qué vendés, falló.

## 4 · Referencias

Dos orígenes: las que da el cliente (cuentas de IG, marcas que le gustan) y las que encontrás.

| Referencia | URL | Categoría | Qué ve el cliente | Qué se toma (**principio**) | Qué NO se toma (**forma**) |
|---|---|---|---|---|---|

**Cómo se descompone una referencia:**

1. Nombrá lo que se ve — *"fondo beige, producto centrado, mucho aire, sans fina con tracking"*
2. Nombrá **por qué funciona** — *"el vacío hace que el objeto se lea intencional y caro"*
3. Quedate con el paso 2. **Ese es el principio.** El paso 1 es la forma, y copiarla es plagio
   con extra pasos.

> Las referencias **fuera de categoría** valen más que las de adentro. Son la forma más directa de
> traer un código que la categoría todavía no tiene. Mirá packaging cuando hacés servicios, mirá
> editorial cuando hacés producto.

**Regla del cliente.** *"Me gusta porque se ve premium"* es `[percepción del cliente, no
verificado]`. Se registra tal cual y después se descompone. La lectura del cliente es un dato sobre
el cliente, no sobre la referencia.

---

## 5 · Por qué algo se ve bien — las 4 palancas

Para leer una referencia sin quedarte en *"está lindo"*:

| Palanca | Qué hace |
|---|---|
| **Forma** | Curvas = natural, suave, cómodo. Ángulos = preciso, técnico, agresivo. El cerebro lo lee antes que cualquier otra cosa |
| **Familiaridad** | Lo conocido se percibe mejor. Por eso las marcas fuertes cambian de a poco y conservan señales |
| **Simplicidad** | Quitar distracciones hace que lo importante se sienta intencional. Lujo es quitar, no agregar |
| **Orden e intención** | Cuando algo está bien compuesto "hace click" sin que haya que analizarlo |

Lo estético no es *verse bonito*: es hacer que el cerebro sienta **orden, intención y placer
visual**.

## 6 · Hallazgos

5-8 hallazgos. Cada uno: marca 🟢/🟡/⚪ + conteo de fuentes + dónde se verificó.

```
🟢 8 de 10 competidores usan azul frío como primario y sans neutra. La categoría es visualmente
   intercambiable en thumbnail. [verificado: IG de 10 marcas, 14-09-2026]

🟡 Solo [marca] usa fotografía de personas reales; le da el mayor engagement de la categoría.
   [1 fuente — señal a confirmar]

⚪ Nadie usa tipografía serif. Hipótesis del vacío: la categoría asocia serif con "viejo".
   A verificar antes de tomarlo.
```

**Ninguno recomienda.** Terminan en *"la categoría hace X"*, nunca en *"deberíamos hacer Y"*.
