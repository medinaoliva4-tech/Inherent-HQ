# ④ Producción

**Pre y Post.** Pre: jornada, briefs, guiones, shot list, permisos, compras y hooks alternos, en una
hoja imprimible para escribir encima. Post: edición y multiplicar — **el primer corte lo hace el
agente, el editor humano solo corrige.**

## Herramientas *(en Inherent OS)*

Pre: la hoja de la jornada · Post: editor de video simple, que carga solo el rol de editor.

## Skills

| Skill | Qué hace |
|---|---|
| `produccion` | El orquestador |
| `pr-pre` | Todo lo que hace falta antes de grabar |
| `pr-post` | Primer corte, marca, derivadas, export y aprobación |

**El proceso está en `brain/WORKFLOW.md`.** El motor de edición *(Remotion, guion visual y página de
aprobación)* está en `brain/motor/`.
