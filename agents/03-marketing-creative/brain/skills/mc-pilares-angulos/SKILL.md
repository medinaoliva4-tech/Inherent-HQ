# Paso 2 · Pilares × ángulos

| | |
|---|---|
| **Consume** | Nodos `producto`, `dolor`, `deseo`, `historia` y `brief` · el radar del ciclo · los canales de la ficha |
| **Produce** | `clients/<cliente>/03-marketing/<AAAA-MM>/pilares-angulos.md` — nodos `pilar-NN` y `angulo-NN`, con `viene_de` al dolor, deseo u oferta de donde salen |
| **Herramienta** | El tablero pilares × ángulos del OS |

## 1 · Los pilares — 3 a 4, cada uno de un nodo de Strategy

| Pilar | Sale de | Para qué |
|---|---|---|
| **Oferta** | El nodo `producto` *(la oferta del bloque 1 del brief)* | Que se entienda qué se vende y por qué vale |
| **Dolor** | Un nodo `dolor` aprobado | Que el ICP se reconozca: confianza |
| **Deseo** | Un nodo `deseo` aprobado | Que el ICP se vea después: aspiración |
| **Autoridad** *(opcional)* | Pruebas, casos, proceso | Que crea que la marca sabe |

🔑 **Un pilar no es un tema: es una promesa que la audiencia aprende a esperar.** Un pilar sin
`viene_de` a un nodo de Strategy no entra.

## 2 · Los ángulos — quién lo ve

**Por defecto: jóvenes · millennials · mayores.** Si el ICP pide otro corte *(decisor vs. usuario,
etapa del negocio)*, se usa ese. Cada ángulo dice:

```
angulo-02 · Millennials
Qué le importa · cómo habla (palabras literales) · dónde vive · qué le da confianza · qué lo aleja
```

Las diferencias salen de las entrevistas reales o del panel sintético *(`[hipótesis]`)*.

## 3 · El tablero

| | Joven | Millennial | Mayor |
|---|---|---|---|
| **Oferta** | idea · canal · peso | | |
| **Dolor** | | | |
| **Deseo** | | | |

- **Cada celda activa lleva:** la promesa en una frase, el canal donde vive y su peso en % del ciclo.
- **Se activan las celdas que el ICP y el resultado esperado piden**, no todas. Una celda vacía es
  una decisión, no un hueco.
- **El total de piezas entra en el techo de la ficha.** Lo que no cabe, no se planea.
- **Lo quemado del radar no entra** en ninguna celda.
